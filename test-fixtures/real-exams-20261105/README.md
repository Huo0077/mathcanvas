# 数据来源与使用说明

本目录是2026-11-05评测用的固定便利样本，不是考试机构发布的原始试卷。

- 多模态数据：OpenMOSS/GAOKAO-MM，固定提交 `76d5193c89655192d053dcf86ead743e0423ec95`，`Data/2010-2023_Math_MCQs.json`。
- 文字数据：OpenLMLab/GAOKAO-Bench，固定提交 `6dbb24f8d8439041e5431c4c184a582182a6ce9c`，`Data/Objective_Questions/2010-2022_Math_I_MCQs.json`。
- 每题的源地址、上游索引、年份卷别题号、标准答案和解析见 `cases.json`。原始文件与图片的SHA256在清单中。
- 上游仓库许可证原样保存在 `mm-LICENSE`、`text-LICENSE`；许可证归属及版权声明以各文件为准。上游仓库许可不代表本项目独立拥有考试题目及所有第三方配图的版权。
- 57张PNG为上游原图；30张 `*-sheet.png` 为本次将原文题干与原图重新排版的图片。没有用人工描述替代题图。LaTeX未排版成公式、不是原卷整页截图。
- 首轮 `mm-000`、`mm-012`、`mm-058` 的新增图注误标了图片角色；当前图片已修正为原有A–D选项在前、主图在后。原始首轮图片保存在本地评测证据目录，不覆盖首轮成绩。
- 源数据质量标记：`text-151` 选项C公式损坏；`text-178` 将三角形ODE识别为方框ODE；`mm-051` 解析存在25/24排版笔误，最终参考值√7仍可独立核验。报告不隐瞒这些缺陷。
- 本批没有已核实的著名联考或模拟题，不能据此声称已覆盖联考。
