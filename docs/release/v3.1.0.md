# MathCanvas v3.1.0

**发布日期：** 2026-10-02 ｜ **类型：** 功能版（在 v3.0.1 之上，新能力走 minor）

## 这一版改了什么

球体与球截面这条线整体交付（实施计划 Task 1–9）：

1. **解析球文档类型**：文档只存**球心 + 半径**，校验有限球心与正半径，`.mgeo` 往返逐值相同；显示网格与截点都是**可重算的缓存**，不是数学真源。
2. **球-平面精确截交**：圆 / **单点切触** / 空集三态，退化容差与模型尺度同源（不把相切近似成一个小圆）。过球心给**精确圆**（`exact.kind = "circle"`、`status = "exact"`）。
3. **场景事务与数值测量**：球心、半径可编辑，可平移，一步撤销；表面积 `4πr²`、体积 `4πr³/3` 标 `exact-input`。
4. **截面接进 `SectionPrimitive`** + **球布尔门禁**：球-球 / 球-实体明确拒绝、留诊断、不改文档；界面也不给"点一下就建"的虚线预览。
5. **3D 渲染**：`SphereGeometry` 光滑球面 + `userData` 拾取身份；**不把经纬细线做成可被选中的棱**。
6. **手工入口**：「常用立体」新增**球体**预设（球心 X/Y/Z + 半径两个字段），属性栏沿用同一套可编辑控件。
7. **工程投影与导出**：主 / 俯 / 左 / 轴测四视图给出**同样大**的圆；SVG / DXF / PDF 三件套均输出。
8. **Agent 动作 `solid.create_sphere`**：动作 / 传输 / 登记三层一起接通，能力表由 `temporarily_unavailable` 翻成 `available`；缺 `center` / `radius` 走 `ask_user`，**不静默填默认**。
9. **Agent 端到端**：一句话造球（本地确定性规划器 → 隔离草稿 → 用户确认 → 一步撤销）。
10. **修复一处审计查出的静默缺口**：球的面积 / 体积测量此前**不会**画在画布上 —— `measurementVisuals.ts` 的 `pointPositions` 是硬编码类型名单、**漏了 `sphere`**，于是 `resolveMeasurementVisual` 返回 `null`；而属性栏照样有数字，所以这个缺口是**静默的**（同一张名单此前漏过一次 `polyhedron3`）。
