# MathCanvas 5.1.1

**发布日期：** 2026-11-22

## Android 移动端 UI 全面重构（画布优先 · Material Design 3 排版）

参考 **Material Design 3 自适应导航** 与 **GeoGebra / Desmos / Apple Freeform** 等主流移动画布应用的信息架构，针对手机竖屏/横屏彻底整理了 Android 端界面层级，大幅释放作图空间并消除工具栏多层堆叠杂乱感：

- **底部导航栏释放 100% 屏宽**（[ModuleRail.tsx](../../apps/web/src/components/ModuleRail.tsx)、[workspace-layout.css](../../apps/web/src/styles/workspace-layout.css)）：
  - 窄屏（`<= 680px`）自动将桌面左侧导航栏切换为 Material Design 3 风格 **底部导航栏（画布 / Agent / 设置）**，带圆角激活胶囊与 `aria-current="page"` 语义标记，让 2D/3D/工程制图画布、Agent 与设置页获得 100% 满宽视野。
- **顶部工具栏去冗归整**：
  - 将原先 4～5 层杂乱折行压减为紧凑 46px 顶栏（`MathCanvas` + 胶囊化 `文件` / `保存`）+ 等宽三段式工作区切换器（`平面几何 | 立体几何 | 工程制图`）+ 单行横向滑动工具条（主工具、构造、更多工具与撤销/重做整齐同排，彻底消除孤立折行）；
  - 隐藏窄屏下无触控意义的桌面状态栏与 Agent/设置页重复顶部标题栏。
- **画布悬浮毛玻璃胶囊与圆角 Bottom Sheet 抽屉**（[AppChrome.tsx](../../apps/web/src/components/AppChrome.tsx)）：
  - `对象列表 / 属性检查器 / ✨ AI` 收纳为画布右上角半透明毛玻璃悬浮胶囊，与 3D 左上角 `视图选项`、底部居中相机控制胶囊对称布局；
  - 对象列表、属性检查器、AI 助手抽屉与「文件 / 构造 / 更多工具」菜单在移动端统一升级为 **圆角 Bottom Sheet**（带顶部把手条与点击外部遮罩关闭，兼容 Android 系统返回键逐层关闭）。
- **工程制图（CAD）、Agent 与设置页移动端深度整理**（[EngineeringWorkbench.tsx](../../apps/web/src/components/EngineeringWorkbench.tsx)）：
  - 手机端工程制图默认收起左右双侧树/属性面板（按需以圆角 Bottom Sheet 弹出），单行工具条完整展示 `显示 44%` 无裁切；
  - Agent 工作区采用底部贴边圆角输入栏与横向紧凑例题卡片，对齐主流移动 AI 对话体验；设置页卡片与标签页留白规整清晰。
