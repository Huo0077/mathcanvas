# MathCanvas 6.0.0（全新「高等数学」十大交互可视化工作台与 AI Agent 大学数学精确解题大版本升级）

**发布日期：** 2026-11-24

## 本版本核心亮点

**`v6.0.0`** 是 MathCanvas 从「中学平面/立体几何与工程制图工作台」迈向 **「中学—大学全学段 AI 原生交互式数学计算与可视化平台」** 的里程碑大版本升级——新增独立 **「高等数学」工作区（10 大大学核心数学交互模块）**，并将底层机器精度数值求解器全面接入 **AI Agent 原生工具链（`ds_action`）与离线确定性规划器**，实现 Windows x64、Android ARM64 与 Web 全平台同步升级：

### 1. 全新「高等数学」交互工作台（覆盖微积分 · 参数/极坐标 · 微分方程 · 偏微分 · 级数 · 线性代数 · 概率统计）
- **一元微积分全能分析台**：自适应加密采样 + Brent 寻根（$10^{-9}$ 容差）精确识别光滑驻点、非光滑尖点（如 $|x|$）、闭区间全局最大/最小值、零点实根、拐点与垂直/水平/斜渐近线；内置 8 点复合 Gauss–Legendre 定积分（正负阴影面积、绝对面积、平均值、曲线弧长 $L$、绕 $x$ 轴旋转体体积 $V_x$）、自动化简解析导数 $f'(x)$ 与任意点 $x_0$ 切线/法线/曲率探针、单点与无穷远极限（自动判别连续/可去/跳跃/无穷间断点）以及双曲线叠加对比 $g(x)$（交点与围成面积）。
- **参数方程与极坐标曲线工作台**：支持参数方程 $(x(t), y(t))$（总弧长、速度/切向量、$dy/dx$、$d^2y/dx^2$、曲率与轨迹动画）及极坐标 $r = r(\theta)$（极坐标网格、扇形面积 $S = \frac{1}{2}\int r^2 d\theta$、弧长、极径与切向量），内置摆线、星形线、利萨茹曲线、心脏线、三叶/四叶玫瑰线、阿基米德螺线等经典预设。
- **自然数学语法 + LaTeX 粘贴 + 完整数学键盘**：原生兼容隐式乘法（`2x^3 - 3x`、`x sin(x)`、`2sin^2(x)`、`sin x`）、全角中文符号、反三角/双曲/对数/立方根扩展函数与 LaTeX 粘贴（`\frac{}{}`、`\sqrt{}`、`e^{-x^2}`），提供行内实时数学排版预览、中文错误提示与可展开三分类数学键盘。
- **右侧属性诊断栏与桌面/移动统一交互**：支持 `900px` 以上三栏完整展示与拖拽调宽（`InspectorResizeHandle`）、底部统一状态栏（一键导出 2D/3D/分屏高清 PNG、`✨ AI 助手` 同屏抽屉、左右栏折叠）、单行可滚模块标签栏、一键复制数值结论，以及公式编辑中途保留上次有效诊断（告别白屏闪烁）。
- **拉格朗日乘数法与等高线相切**：基于拓扑网格边 Marching Squares 提取目标函数等高线族与隐式约束曲线，支持沿约束曲线拖拽实时显示 $\nabla f$ 与 $\nabla g$ 夹角及估计乘子 $\lambda$，内置多初值阻尼三维 Newton–KKT 精确驻点求解器与 2D↔3D 曲面约束抬升同屏联动。
- **常微分方程（ODE）与二维自治相平面**：一阶 ODE 斜率场 + Dormand–Prince RK45 自适应双向积分曲线簇；二维自治动力系统 $x' = P(x,y), y' = Q(x,y)$ 速度归一化向量场、零斜线（Nullclines）以及雅可比矩阵迹/行列式/特征值自动平衡点稳定性分类（稳定/不稳定结点、焦点、鞍点、中心）。
- **多元显式 3D 曲面极值、鞍点与方向导数**：支持 $z = f(x, y)$ 交互式三维网格渲染、多初值二维 Newton 驻点搜索、二阶 Hessian 判别式 $\Delta = AC - B^2$ 分类（极大值、极小值、马鞍点），以及任意点 $(x_0, y_0)$ 梯度 $\nabla f$、方向导数 $\partial f/\partial l$ 与局部切平面展示。
- **偏微分方程（PDE）实时数值仿真**：内置独立 WebWorker 60fps 场演化引擎与自动 CFL 稳定性子步进，支持二维热传导方程、二维波动方程（支持点击画布实时注入高斯波包/热源脉冲）以及二维泊松/拉普拉斯方程 SOR 超松弛稳态势场与等势线/负梯度通量场求解。
- **无穷级数与重积分可视化**：基于一维截断幂级数 Jet 自动微分的最高 20 阶精确泰勒展开与余项对比；傅里叶级数合成、频谱柱状图、轮盘本轮（Epicycles）动画与吉布斯超调分析；直角坐标（支持一键交换积分次序）与极坐标（自动含雅可比因子 $r$）二重积分扫描切片及平面向量场散度/旋度实时探针。
- **线性代数变换与概率统计实验**：$2\times 2$ 矩阵同伦连续变换动画 $(1-t)I + tA$、实/复特征值、单位特征向量与精确 SVD 单位圆→奇异椭圆映射；正态、$t$、卡方、指数、二项、泊松 6 大分布区间概率阴影计算及中心极限定理（CLT）动态抽样实验。
- **纯前端 CSP 安全字节码引擎**：自研零 `eval` / 零 `new Function` 扁平逆波兰（RPN）字节码编译器与符号一阶/二阶偏导求导器，完全兼容 Tauri 2 桌面与 Android 严格安全策略。

### 2. AI Agent 大学数学精确求解与工作台无缝联动
- **10 类机器精度内核求解工具接入 `ds_action`**：在 [`dsActionTools.ts`](../../apps/web/src/agent/dsActionTools.ts) 的 `query_measurement` 中扩展 `calculus_1d`、`lagrange_2d`、`surface_3d`、`ode_solve`、`taylor_series`、`fourier_series`、`double_integral`、`div_curl`、`matrix_2x2` 与 `probability`，彻底消除大模型心算根、积分、乘子与特征值的误差。
- **离线确定性高数规划与零回归隔离**：新增 [`higherMathPlan.ts`](../../packages/agent-core/src/solver/higherMathPlan.ts)，在严格隔离初高中立体几何与圆锥曲线基准题（零拦截、零回归）的前提下，支持离线精准求解高数题目并自动生成编译校验通过的函数/几何图元。
- **Agent ↔「高等数学」一键状态同步**：在 `Agent 工作区` 或 `✨ AI 助手` 提问任意高数问题后，函数、区间、约束、初值、矩阵或分布参数自动同步至「高等数学」工作台（[`calculusStore.ts`](../../apps/web/src/calculusStore.ts)），切页即可交互探索。

### 3. Android 自适应品牌启动图标补齐与仓库归档升级
- **Android 全密度与双层自适应启动图标**：补齐前景/背景分离矢量源与全套 22 份 `mipmap-anydpi-v26`（`ic_launcher.xml`、`ic_launcher_round.xml`）及 `mipmap-mdpi..xxxhdpi` 图标资产，并在 [`android-post-init.mjs`](../../scripts/android-post-init.mjs) 自动覆盖默认模板占位图并清理遗留机器人矢量图。
- **双语文档、官网 SEO 与归档整理**：新增英文文档 [`README.en.md`](../../README.en.md)、学术引用 [`CITATION.cff`](../../CITATION.cff)、文档导航 [`docs/README.md`](../README.md) 及官网结构化元数据，归档根目录历史审计与早期变更日志。
