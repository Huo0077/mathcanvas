# MathCanvas 4.4.0

**发布日期：** 2026-11-09

## 本版更新

这一版是 **Agent 可靠性整改（W0–W9）** 的工程交付版，重点不在"换模型"，而在让系统把
"回答了什么、验过什么、还缺什么"说准确。

- **逐问交付与诚实状态**：宿主侧新增答案合同与验收；空白正文、空目标、缺结构值、被独立否证的候选不再显示成"已回答"；界面逐问显示答案、缺项与核验说明，旧消息明确标"历史回答，未重新核验"。
- **协议恢复**：分支字段说明与解析器同源；纠错反馈带稳定原因码、字段路径与被拒分支，并有预算地只给一次纠错；非法批次零执行。
- **题意与折叠题**：合并问句拆成逐问目标；①②/(1)(2) 小问作用域分离；折前/折后状态、显式依赖与条件消费清单可追溯；折叠题支持正方形、口语问法、折角目标、对角线矛盾检查与辅助垂足构造（原 24 题独立核心判据 24/24）。
- **有限数学核验**：坐标距离/垂直、限定区间二次最值、双曲线垂足离心率、椭圆离心率范围；两条历史错解被独立否证，支持也只标"实例验证"，不冒充形式证明。
- **题图证据**：读数绑定附件/哈希/归一化区域/来源；缺失关键尺寸或向量方向时生成受控重读计划（最多 2 次）；同区域冲突用户更正优先且保留被覆盖记录。
- **有限三视图**：轴对齐长方体与 L 形柱体；共享轴/单位/维度冲突与不可观测切槽深度都明确拒绝或要求补充；体积用解析分块与闭合网格两条独立路径互验。
- **评测与灰度**：新增能力清单、结构化评分器、数据集 schema、8 题开发集与 12 题**开放**留出集、离线报告器（全量分母 + Wilson 区间）；新增五个默认全关的灰度开关与未知版本守卫。

## 重要边界

- 本版**没有运行真实模型或线上入口评测**，因此不提供准确率、成功率或"提升 N 个百分点"的结论。
- **W6 的自动重读尚未接线**：题图仍由用户手动"重读选区"；本版只交付证据与策略层。
- **W7 只接受结构化三视图事实**，不解析自然语言/图像；圆柱、斜截面与遮挡歧义题明确标"超出能力"。
- 12 题留出集是**开放集**（内容在仓库，`blind:false`），不是盲测；A/B 双轨适配器未接生产入口。
- 全仓 eslint 仍有 30 条既有 warning（未使用变量）；**0 error**。
