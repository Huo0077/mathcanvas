# MathCanvas 5.2.0（Windows & Android 整合正式版）

**发布日期：** 2026-11-22

## 本版本核心亮点

**`v5.2.0`** 是面向 **Windows x64 桌面端** 与 **Android ARM64 移动端** 的全平台整合正式版，汇总了自 `v5.0.0` 以来的全部移动端原生升级、Agent 图元显示根治修复与开源仓库体系整理：

### 1. Agent 图元框全量展示与构图修复（Windows & Android 同步生效）
- **预览态图元框实时同步**：Agent 完成作图进入隔离草稿预览态后，图元框顶部立即展示 **「AI 预览图元（待确认写入）」** 分组与 `预览 N` 计数徽标，点击即可在属性栏查看详情，且保持主文档提交前隔离契约。
- **关键点、棱、面默认展开**：Agent / 题目构造的多面体（如四棱锥 `P-ABCD`、正三棱柱 `ABC-A₁B₁C₁` 等）及含命名顶点的独立/折叠面在预览与提交后均默认展开，不再将关键顶点、棱与面藏在折叠行内；手工模板实体与旧 `.mgeo` 夹具保持原有折叠行为。
- **保留实体面内合法构造子面**：修复 `consolidateSolidScaffolding` 误删落在多面体面内子面（如底面 `ABCD` 内的 `△AEF`）的问题，仅当两面顶点集完全一致时去重。
- **2D 草稿自动取景补全**：将圆、圆弧、椭圆、抛物线、双曲线、线段、直线、射线、折线与交点统一纳入自动取景范围。

### 2. Android 端原生能力与 Material Design 3 移动端 UI 重构
- **画布优先移动排版（`<= 680px`）**：采用底部导航栏（画布 / Agent / 设置）释放 100% 屏宽，精简双行顶栏与单行横向滑动工具条，对象/属性/AI 采用画布右上角毛玻璃悬浮胶囊 + 圆角 Bottom Sheet 抽屉，兼容 Android 返回键逐级关闭。
- **原生公共下载与系统分享**：通过受控 `@JavascriptInterface`（`MathCanvasAndroid.deliverExport`）与 Android 10+ `MediaStore.Downloads` 零权限写入公共 `下载/MathCanvas/` 目录，并通过 `FileProvider` 调起系统分享面板；配合 R8 保留规则、浅色冷启动主题、`allowBackup="false"` 与 `ChaCha20 + HMAC-SHA256` 应用私有加密凭据库。
- **2D/3D 触控手势与工程制图移动适配**：支持 2D 单指平移/双指捏合缩放、3D 单指旋转/双指缩放平移，工程制图手机端默认收起双侧面板按需展开。

### 3. 开源仓库与官网门户同步升级
- 全面美化 [README.md](../../README.md)（Logo 居中横幅、徽章矩阵、Mermaid 架构图、全平台下载表），补齐 GitHub 社区治理规范（Bug / 题目构图 / 功能建议 Issue 表单模板、PR 模板、[CONTRIBUTING.md](../../CONTRIBUTING.md)、[SECURITY.md](../../SECURITY.md)）。
- 同步升级官网门户 [`portal/`](../../portal/index.html) 至 `v5.2.0` 整合版，提供 Windows 三件套 + Android APK 2×2 下载卡片与校验文件直链。
- 升级 [`.github/workflows/android-release.yml`](../../.github/workflows/android-release.yml) 为 **Unified Release (Windows & Android)** 流水线，打 `v*` 标签自动并行构建并整合发布全平台产物。
