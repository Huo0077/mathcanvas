# MathCanvas v3.2.0

**发布日期：** 2026-10-02 ｜ **类型：** 功能版（在 v3.1.0 之上，新能力走 minor）

## 这一版改了什么

### 1. 新增 HTML 导出（自包含快照 + 可再导入存档）

导出菜单新增「**导出 HTML**」，产出一个单文件、**零外部引用**的 `.html`：

- 内嵌**既有 SVG 产出器**的产物（不是重画一遍）：平面几何走标准视野（含网格），工程制图走四视图。
- 文件正文里写清「**这次导出漏了什么**」：隐藏对象、导出器画不出来的类型、工程视图诊断；**无损失时明确写"无"** —— 收件人拿到的是图，他有权知道少了几个对象。
- 内嵌 `.mgeo` 源码，使这份 HTML **兼作可再导入的存档**（拖回应用即原样打开，标签/样式/参数都在）。
- 结尾写**格式版本**与**应用版本**（桌面外壳给真版本；浏览器里如实写 `unknown`）。
- **立体几何明确拒绝**：3D 画布是 WebGL、没有矢量产出器，照平面分支走会得到一张空图 —— 所以这里给一句人话并**不产出文件**，而不是"导出成功、里面只有坐标网格"。
- 注入防护：文档派生文本一律转义；内嵌 JSON 把 `<` 写成 `\u003c`（用户标签里可以出现 `</script>`，那是注入而不是理论风险）。

### 2. 三处修复

- **拖动/滚轮立刻取消进行中的自动取景动画**：过去 `cancelFitAnimation()` 只在卸载时调用，于是"换文档触发取景"之后在 250 ms 窗口内开始拖，剩下的帧会把用户刚拖出来的视角覆盖回去。顺带把取景动画的三态做成可观测读数 `data-fit-animation`（`running` / `done` / `cancelled`）。
- **悬停读数跟着内容重算，不再只跟着指针**：`data-preview-hovering` 过去只由 `pointermove` 写入，而预览几何是内容同步建的 —— "指针先到、预览后到"时属性会永远停在 `false`。现在内容同步之后按最后一次指针位置再算一次（`pointerleave` 会清掉记住的位置，不会凭空造悬停）。
- **本地规划器不再把分析题当成建模指令**：把"这个正方体的内切球半径是多少"喂进去，过去命中的是「正方体」条目 ⇒ **去新建一只正方体**而不是回答读数。现在"没有任何建模动词、却在问读数"的句子一律不认建模意图，落到既有的"老实问路"。边界如实：只挡没有建模动词的问句（"画出这个正方体的内切球"照旧走建模）。

## 已知边界（与上一版相同）

- HTML 快照**不可交互**（拖点、联动数值不在本版）；样式 / 主题 / 字体不可定制；一份 HTML 只装当前这一个文档。
- 平面几何的 HTML 用**标准视野**（复用 `exportSvg` 的固定 `WORLD_BOUNDS` / `VIEWBOX`，含 21×13 网格），所以用户若平移/缩放过，HTML 里的图与屏幕上看到的**不完全一样** —— 换来的是同一份文档永远得到同一张图。
- 产物格式版本一旦发布就不该随意改（改了要按版本号区分，否则老文件认不出）。
