# MathCanvas 5.1.2

**发布日期：** 2026-11-22

## 修复 Agent 作图后关键点、线、面在图元框缺失的问题

本版本定位并修复了 Agent 完成作图后，图元框（对象列表）仅显示部分辅助图元、关键顶点/棱/面无法看到及部分构造子面被误删的 4 处根因：

- **预览态图元框实时同步全部 AI 草稿图元**（[App.tsx](../../apps/web/src/App.tsx)、[AlgebraView.tsx](../../apps/web/src/components/AlgebraView.tsx)、[workspace-layout.css](../../apps/web/src/styles/workspace-layout.css)）：
  - Agent 完成作图进入隔离草稿预览态后，图元框顶部立即呈现 **「AI 预览图元（待确认写入）」** 分组与 `预览 N` 计数徽标，列出全部待落盘点、棱、面并支持点击联动右侧属性栏核查，同时保持主文档提交前隔离契约。
- **Agent 构造的多面体与命名折叠面默认展开**（[AlgebraView.tsx](../../apps/web/src/components/AlgebraView.tsx)）：
  - 预览态与确认写入后，Agent 构造的多面体（如四棱锥 `P-ABCD`、正三棱柱 `ABC-A₁B₁C₁` 等）及含命名顶点的独立/折叠面默认展开，直接显示全部**顶点 / 棱 / 面**，无需再手工点开折叠行；手工模板实体（立方体/圆柱/圆锥拓扑）与既有 `.mgeo` 夹具保持原有折叠行为。
- **保留实体面内的合法构造子面**（[dsActionTools.ts](../../apps/web/src/agent/dsActionTools.ts)）：
  - 修复 `consolidateSolidScaffolding` 将落在多面体面内的子面（如底面 `ABCD` 内的 `△AEF`）误判为重复面删除的缺陷，改为仅当两面顶点集完全一致时去重。
- **2D 草稿预览自动取景覆盖曲线与线段**（[GraphicsView.tsx](../../apps/web/src/components/GraphicsView.tsx)）：
  - 自动取景范围扩展至圆、圆弧、椭圆、抛物线、双曲线、线段、直线、射线、折线与交点，避免纯曲线 2D 构图偏离视口。
