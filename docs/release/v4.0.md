# MathCanvas v4.0

**发布日期：** 2026-10-20 ｜ **类型：** 跨大版本（v3.2.0 → v4.0.0；566 个提交，能力面从"能画"扩到"能按题面构造并核验"）

## 这一版改了什么

### 1. 题面读入：让卷面原话进得来

- **LaTeX 与 OCR 归一**：`\triangle`、`\angle`、`\frac` 一类卷面写法先归一成语义句；`0`↔`O`、全角符号等常见 OCR 误识按**限定表**纠正，表外不做猜测。
- **点名一种定义**：撇号全部变体（`'` / `′` / `’` / `´`）归一成同一字形；ASCII 数字后缀按下标读（`A2` → `A₂`、`A12` → `A₁₂`）；点名放宽到两段后缀，正四棱柱 `A₂B₂C₂D₂` 这类题面终于能对上计划里的名字。
- **形状从句**：`Rt△ABC` / `△ABC` 都认（此前只认"三角形"三个字 ⇒ 单字母角 `∠C=90°` 无处落）；正五、正六边形底面按正多边形代表元支持。
- **条件读取器扩表**：定比分点的分数写法 `AE=2/5 AD`、`为` 表二面角、单字母角按形状环解析、点在圆锥曲线上、弦长、线面角、函数与直线的交点个数、等边长度；数字句拆分与前导条件词剥离减少"整句落进未解析"。
- **不静默丢条件**：读不出的题设进 `unverified` 并给出理由，"答案句"（`（2）求…`）不再被当成题设。

### 2. 解析式构造：不靠模型也能把图造出来

新增一批**按题面条件直接造坐标**的构造器，覆盖高中立体几何的主要可判类型：

- 四面体（六棱长）、长方体（三棱长）、正四棱锥（侧棱 + 底棱）、正三棱锥（棱长）、正三棱柱；
- 梯形棱柱（含基面绕序排序）、直角三角形棱柱、垂直平面的棱锥、两面二面角构型；
- 折图按题面比例合成（"将 △AEF 沿 EF 翻折" ⇒ 系统自己补那一笔折）；
- 圆台作为**参数化动作**（按既有的多边形近似落地）、球作为**派生对象**跟随宿主实体（外接球/内切球按宿主自己的坐标核验，不采信求解器的说法）；
- 平面多边形按**度量条件**构造（不再只认坐标）。

### 3. 空间原子动作

立体几何此前缺"细粒度动作"，模型只能拿 `create_polyhedron` 硬凑。本版补齐：

- `solid.create_segment` —— 只给两个点名，坐标由前面几笔决定（不让模型手写第二份真源）；
- 自由空间点、点投影、点旋转、点平移、对平面反射、线面交点；
- 开放多面体与折角可直接画（不再被"必须闭合"挡住）。

### 4. 核验判据：说得出"哪里不满足"

- **点在线段上**拆成两条判据（共线 / 落在段内），因为"不在直线上"和"在延长线上"该改的东西不同；
- 点在三角形内、锐角/直角/钝角三角形、锐角不等式、向量点积条件、外心重建、点在圆锥曲线上；
- 线面角**真的量**、弦长、函数与直线的交点个数、立体隐藏边的虚线证据；
- 渲染证据新增**标签碰撞风险**与**近重合/共线点**告警 —— 图"画出来了但看不清/不成立"能够显形。

### 5. 救援与修复：只救不抢

- **见证搜索（按题面条件搜坐标）默认开启**：候选已满足题设时一步不动，只有核验没通过才搜，且第二遍必须真的通过才采用。
- 题面说要折、计划里没有折 ⇒ 系统**补**那一笔（补了什么写进 `assumptions`）。
- 结构缺陷与折缺陷的**合并救援**有用例钉住。
- 修复提示按失败签名扩表：点名缺失、动作顺序错、信封被写成 JSON 字符串、`⊥平面` 的几何含义等。
- 预算：`generation` / `network` 由 6 抬到 8（用户 2026-10-15 批准）；`point3` 投影求解器加**墙钟预算**，不再无限期等。

### 6. 形式证明（Lean 4）

后端准入落成**十栏审查契约**（接后端不再靠改数组），**一个目标类已闭环**（真 `lake env lean` 核验），延迟返回的证明结果在图形已变化时**过期**，`npm run proof:smoke` 可单独跑。

### 7. 评测与基准

- 付费 exam run 收成**一条受门禁的单命令**（`--exam-run`，无授权即拒绝），成本未实测时记 `null` 而不是 `0`；
- 样本与阈值在看到任何付费结果**之前冻结**；
- 报告契约新增 **planning 层**（计划有没有被编译接受），"模型反问"有独立状态 `clarification`；
- 记录 **30 题联考试卷作图评测**。

### 8. 课程与题集

2025 课标内容按单元建索引（fail-closed 审计）、跨域数学校验用例集。

## 验证与边界

- **单测**：全库 **457 文件 / 4852 项通过 + 1 todo / 0 失败**（`vitest run`，174.86 s）。
- `npm run typecheck` **exit 0**；`npm run lint` **exit 0（0 error / 15 warning）**。
- **本机启动实测**（release exe，非安装包）：真窗口句柄 `1376356`、标题 `MathCanvas`、`Responding=True`、存活 T+12s。
- **本版没有跑的（如实）**：全量 **e2e 未跑**。上一版（v3.2.0）跑过 184 通过；本版改动面很大，e2e 的结论要**重新跑过才能引用**，这里不引用旧数字。
- **MSI 的"装 → 启动 → 卸载"未验**：本会话非管理员，MSI 按 Tauri 默认是每机器安装；NSIS（每用户）那一半在 v3.1.0 验收时走完过完整一圈。
- 教师/学生走查未做；立体几何的 3D 画面进 HTML、GeoGebra `.ggb`、题目截图识图**都不在本版**；真题四族的真实 provider 质量仍以 [`docs/current-status.md`](../current-status.md) 为准，不由本文件代替。

## 已知边界（与上一版相同）

- HTML 快照**不可交互**；一份 HTML 只装当前这一个文档。
- 平面几何的 HTML 用**标准视野**，用户平移/缩放过时它与屏幕上看到的**不完全一样**。
- 产物格式版本一旦发布就不该随意改（改了要按版本号区分，否则老文件认不出）。
