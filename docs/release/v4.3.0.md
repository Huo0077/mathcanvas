# MathCanvas 4.3.0

**发布日期：** 2026-11-05

## 本版更新

- **立体拖动与联动**：绑定轨迹的动点可以直接用鼠标左键沿轨迹拖动。拖动上游点时，依赖的点、线、面等图元同步预览，不再等松手才跳到新位置。
- **体积测量修复**：修改立体顶点后，测量改用实际面边界计算并自动更新，不再沿用旧尺寸参数。未编辑的参数化立体仍保留解析体积公式；编辑后的多面体边界计算标为数值近似。
- **编辑结果恢复**：重新加载已编辑立体时不再重复生成顶点、棱和面，避免图形重叠与重复标识报错。
- **外接球与内切球作图**：在属性栏对应读数旁选择“作图”，即可生成跟随来源的半透明球体，支持显示、隐藏、一步撤销及保存。不存在或退化的球禁用作图。
- **题图识别与模型兼容**：包含桌面题图识别与 DeepSeek 兼容更新，支持同题题干与配图的识别、编辑和发送。
- **立体题解析与核验**：包含四道立体题的入口保真、解析构造、派生垂足、命名分点和折叠映射改进；目标结果与题设核验分开呈现。该改进不代表任意题目或真实模型均已通过验证。

## 下载

Windows x64 提供 NSIS 安装程序、MSI 安装包和免安装程序。所有安装包均由本次发布源码重新构建。
