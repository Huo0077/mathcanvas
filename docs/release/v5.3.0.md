# MathCanvas 5.3.0（新增线面角与空间直线夹角全链路测量与 3D 教学可视化）

**发布日期：** 2026-11-24

## 本版本核心亮点

**`v5.3.0`** 补齐立体几何三大核心空间角体系——在既有「二面角」基础上，新增 **线面角（`linePlaneAngle`）** 与 **空间直线夹角（`lineAngle`，全面支持相交、异面与平行直线）** 的精确求解、3D 教学可视化、属性栏精确三角函数读数及 AI Agent 查询工具，Windows x64 与 Android ARM64 全平台同步生效：

### 1. 线面角测量与 3D 垂线/射影可视化
- **任意点击顺序自动识别**：选中任意 1 条空间直线/线段/射线/棱与 1 个空间面（`face3`）或无限平面（`plane3`），按 $\theta = \arcsin\left(\frac{|\vec{d}\cdot\vec{n}|}{\|\vec{d}\|\|\vec{n}\|}\right) \in [0, \frac{\pi}{2}]$ 精确计算，并自动区分**斜交 / 垂直 / 平行 / 在平面内**。
- **3D 教学辅助图元**：选中来源时自动在三维画布中画出**交点、虚线垂线段（$P \to H$）、平面内射影线（$I \to H$）、垂足直角方框与线面角弧线**，并常驻浮动读数标签。

### 2. 空间直线夹角与异面直线平移可视化
- **标准锐角/直角口径**：选中任意 2 条空间直线/棱（或 4 个空间点），按 $\theta = \arccos\left(\frac{|\vec{u}\cdot\vec{v}|}{\|\vec{u}\|\|\vec{v}\|}\right) \in [0, \frac{\pi}{2}]$ 取锐角或直角，彻底修正端点方向相反时误出钝角的问题；自动识别**相交直线 / 异面直线（同步给出公垂距）/ 平行直线**。
- **异面直线「平移法」3D 还原**：相交直线在交点直接画角弧与直角标记；**异面直线**在 3D 场景中自动将第二条直线平行平移至与第一条相交，以虚线画出**平移辅助线、公垂线连线与夹角弧线**。

### 3. 属性栏精确三角读数、快捷入口与 AI Agent 升级
- **属性栏精确读数与一键复制**：线面角与空间直线夹角全面接入弧度、角度换算与**精确根式/分数 `sin` / `cos`** 展示与一键复制，且随顶点拖动实时重算。
- **快捷测量入口**：在三维画布左上角「视图选项」与右侧属性栏「三维视图选项」中与「测量二面角」并列新增 **「测量线面角」**、**「测量直线夹角」** 快捷按钮及分步多选引导。
- **Agent 工具增强**：[`dsActionTools.ts`](../../apps/web/src/agent/dsActionTools.ts) 的 `query_measurement` 扩展支持 `line_plane_angle`、`line_angle` 与 `dihedral_angle`，可直接返回弧度、角度、`sin`、`cos` 及相交/异面关系与公垂距。
