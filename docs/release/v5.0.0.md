# MathCanvas 5.0.0

**发布日期：** 2026-11-20

## 首个正式版本重点更新

- **智能读题补线与「以线推面」**：输入常规中学数学题目（无需刻意写“作出某平面”或小写/分隔写法），Agent 自动提取补齐辅助线段（如 `AE`、`CE`），并直接由相交辅助线与动点推测生成对应空间面（如 `面 AEC`），复用原有顶点与动点 ID 实现拖动实时联动。
- **左/右侧工作台全链路联动优化**：Agent 构图进入草稿预览态后，左侧对象栏同步展示 `预览` 图元与 **「面（构造 / 辅助）」** 独立分组；支持两线定面、单点关联平面展示、点面互绑；移除画布冗余三角浮标，在右侧属性栏集中展示二面角/角度与 **`sin` / `cos` 及精确形式一键复制**；二维平面/圆锥曲线/导数切线与三维立体工作区自动分流不串台。
- **Agent 体验、模型服务与桌面壳打磨**：
  - 修复并上线「往期对话」面板，支持完整历史问答与思考过程回溯；
  - 设置页模型服务扩充至 **13 种主流预设**，通过桌面端 Rust IPC 支持 **「自动获取」** 可用模型列表；
  - 丰富「偏好设置」（界面字号与阅读密度、减少动态效果、选中/测量自动展开属性栏、3D 默认视角、新题绘图自动清空旧图元及实验性功能统一收纳），精简设置架构移除冗余「高级 / 开发者评测」页；
  - 更新桌面端正式应用图标并隐藏 Windows 启动命令行黑框。
- **面向对象首页与文档体系定版**：重写面向用户的 `README.md`，全面同步变更日志与进度文档。
