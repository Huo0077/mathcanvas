# MathCanvas 5.2.1（精确内切球求解、多实体球心联动与正四面体题设解析修复）

**发布日期：** 2026-11-23

## 本版本核心修复

**`v5.2.1`** 聚焦立体几何 Agent 在「多子多面体内切球 + 球心构面/测二面角」类高考/竞赛难题中的根因修复，Windows x64 与 Android ARM64 全平台同步生效：

### 1. 内核内切球求解器升级为精确 $4\times 4$ 面平面线性求解
- 重构 [`packages/geometry-kernel/src/solidDerived.ts`](../../packages/geometry-kernel/src/solidDerived.ts) 的 `solveInsphere3`：先对共面面片去重，再利用 $\mathbb{R}^4$ 贪心正交残差选取 4 个线性无关的面平面方程 $[n_i, 1]\cdot(x, y, z, r) = -c_i$ 进行高斯消元求解，并对全部面验证内距与离散度。
- 彻底修复旧版六轴（$\pm x/\pm y/\pm z$）坐标搜索在非轴对齐四面体（如正四面体 `PABC` 内切分出的子三棱锥 `T-PAB`、`T-ABC`）及任意旋转凸多面体上卡死于等距脊线、误报「该实体没有内切球」的缺陷；无内切球实体（如长方体、歪斜立方体）仍如实返回 `undefined`。

### 2. 多实体内切球宿主精准定位与球心点全链路贯通
- 修复 [`apps/web/src/agent/dsActionTools.ts`](../../apps/web/src/agent/dsActionTools.ts) 中 `executeHostInsphere` 兜底误匹配画布首只 `polyhedron3` 的问题，改为优先按 `compiled.aliases[resolvedAlias]` 精确查找对应子多面体。
- 内切球创建成功后自动将球心注册到 `points3`，打通 `resolveSphereCenter3` 与 `construct_segment` 对派生内切球心的距离/角度测量、线段连接（自动物化 `point3`）以及构面（如 `平面 MAB`、`平面 NAB`）。

### 3. 题设解析支持「各棱长均相等的正四面体」类常见表述
- 扩展 [`packages/agent-core/src/diagramObligations.ts`](../../packages/agent-core/src/diagramObligations.ts) 正四面体匹配模式，支持前置/后置「各棱长均相等的 / 棱长均相等的 / 各棱长均为 N 的」、连字符写法 `P-ABC` 以及「各棱长均相等的四面体 / 三棱锥」，消除残余关键词 `相等` 触发的 `source_coverage_incomplete` 误拦截。
