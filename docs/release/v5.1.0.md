# MathCanvas 5.1.0

**发布日期：** 2026-11-22

## Android 正式版重点更新

- **Android 原生外壳、安全区避让与系统返回键全栈打通**：
  - 适配 Android 15/16 Edge-to-Edge 浅色状态栏与导航栏，通过 `WindowInsetsCompat` 统一避让状态栏、挖孔屏与软键盘 IME，配合浅色冷启动窗口主题消除暗色模式启动黑闪；
  - 接入 Android 系统返回键与全面屏侧滑返回（`OnBackPressedCallback` → `window.__mathcanvasHandleAndroidBack`），按优先级逐层关闭上下文菜单、弹窗、侧栏抽屉、Agent 会话抽屉、返回主画布直至退出应用；
  - 加固应用清单（开启 WebGL 硬件加速、`android:windowSoftInputMode="adjustResize"`、`android:allowBackup="false"` 防止本地加密凭据库被自动备份、`android:roundIcon` 圆形图标与云端强制 HTTPS 的 `network_security_config.xml`）。
- **原生公共下载目录与 Android 系统分享面板**：
  - 新增白名单受控导出通道 `export_document_file`（支持 `.mgeo` / `.svg` / `.png` / `.csv` / `.dxf` / `.pdf` / `.html`，32 MiB 上限，防覆盖命名）及原生 `MathCanvasAndroid.deliverExport` 桥接（含 R8 混淆保留规则）；
  - Android 10+ 零存储权限自动通过 `MediaStore.Downloads` 写入公共 **`下载/MathCanvas/`** 目录，并通过 `FileProvider` 唤起 Android 系统分享面板（可直接转发至微信、QQ、邮件或文件管理器）。
- **Rust 移动端加密凭据库与非阻塞网络探测**：
  - 内置 `VaultSecretStore` 持久化本地加密凭据库（`ChaCha20` + Encrypt-then-MAC `HMAC-SHA256`、`0o600` 权限、`zeroize` 内存清零），API Key 跨重启安全留存；
  - `provider_check` 升级为异步非阻塞探测（网络请求期间释放锁），避免移动慢网下阻塞界面响应；启动异常诊断同步接入 `adb logcat`。
- **移动端触控、Agent 会话抽屉与横竖屏深度适配**：
  - 2D 画布支持双指捏合缩放/平移、空白区单指平移与 `r=14` 透明触控热区；3D WebGL 立体几何支持双指捏合缩放与硬件加速渲染；
  - 窄屏 Agent 工作区新增顶部 **`对话 (N)`** 滑出抽屉与 **`＋ 新对话`** 快捷入口；
  - 精简手机端顶栏、文件单列菜单、工程制图工具条、`40px` 紧凑状态栏、全宽 Copilot 抽屉及横屏紧凑顶栏（`44px` 粗指针触控热区）。
- **Android 自动化发布流水线与本地一键打包**：
  - 新增跨平台本地签名打包脚本 `scripts/android-package.mjs` 与仅限 `v*` 标签触发的 GitHub Actions 发布工作流 `.github/workflows/android-release.yml`，自动完成对齐、签名、`apksigner verify` 校验与 GitHub Release 发布。
