# MathCanvas v4.1.0

**发布日期：** 2026-11-02 ｜ **类型：** 特性版（v4.0.1 → v4.1.0；**UI/UX 深度重构与人机交互手感全面升级**）

## 这一版改了什么

v4.1.0 是一次聚焦**人机交互体验、操作手感与作图心流**的重大升级。针对长期存在的“按键与功能交互逻辑反人类、画图手感割裂、阻断操作多”的核心痛点，经过对主流数学工具（GeoGebra、Desmos）与工业级生产力软件（Figma、AutoCAD）的深度对照，全面落地 UI/UX 体验重构，实现作图连贯、同屏共创与专业级键鼠手感。

### 1. 连续作图心流与统一画布落点（Sticky Tools）

- **连续作图心流（Sticky Continuous Drafting）**：平面作图工具（点 `point`、直线 `line`、线段 `segment`、射线 `ray`、圆 `circle`、圆弧 `arc`、折线 `polyline`）及 3D 作图工具在完成一个图元创建后保持激活状态（`center: null`, `sticky: true`），工具按钮保持高亮状态，支持一气呵成连续绘制多个几何图元（如连画三条线段构成三角形），彻底消除画完单个图元被迫中断清空工具的阻断体验。
- **统一空白画布点放置**：统一平面画布空白处/曲线上直接点击添加点图元（`creationMode === "point"`），补齐与线/圆同构的直观落点交互，不再强制依赖从顶栏固定位置插入点。
- **轻量退出与解脱机制**：在画布任意位置按 `Esc` 键或点击鼠标右键（`contextmenu`）直接解脱取消当前工具模式或撤回正在拉拽的橡皮筋第一落点，退回自由选择/平移模式，保持与主流桌面软件操作习惯高度一致。
- **橡皮筋端点与交点预览自适应互锁**：当处于拉拽中途时端点精准吸附交点，处于初始或选择态时准确固化交点并平滑解除粘滞。

### 2. 智能级联删除与单步事务化（Cascade Delete）

- **依赖拓扑闭包分析**：在 `packages/scene-graph/src/deletion.ts` 中实现图元依赖图分析工具 `primitiveDirectDependencies` 与下游递归依赖闭包计算器 `cascadeDeletionClosure`，遍历 2D 与 3D 拓扑 DAG 依赖关系。
- **单步批量原子删除**：在 `apps/web/src/structureCommands.ts` 中将用户发起的对象删除接入 `cascadeDeletionClosure`，删除父图元（如顶点 `A`）时自动将所有下游依赖图元（如线段、以点定义的平面等）一并纳入批量单步事务（`applyBatch`）。
- **彻底消除阻断弹错与支持单步撤销**：废除此前弹出 `"object is referenced by another object"` 强行阻断操作的设计；删除操作在撤销栈中仅占一步，按一次 `Ctrl+Z` 即可完整恢复父图元及其所有下游级联依赖。

### 3. 动点在轨直接绑定与画布直通（Direct Curve Binding）

- **画布直通在轨动点绑定（Drop-to-Bind）**：在 `apps/web/src/curveBinding.ts` 中实现高精度最近曲线吸附目标计算器与动点绑定构造器，支持将自由点直接拖拽贴合至曲线轨（直线、线段、射线、圆、圆弧、抛物线、双曲线、函数图像等全量曲线）自动建立在轨约束，并具备 DAG 循环依赖防护。
- **拖拽磁吸光环与徽标**：自由点靠近曲线 14px 阈值时触发高亮贴轨光环与 `贴轨「<曲线名>」` 徽标指示，松手即时完成绑定。
- **属性栏交互滑轨与快捷解绑**：为在轨动点提供直观的路径参数滑轨 `<input type="range" aria-label="路径滑轨" />`，与精确数值框实时双向同步；提供「解绑为自由点」按钮，一键释放约束恢复自由拖拽。

### 4. AI Copilot 同屏人机共创抽屉与实时 Ghost 草稿检视（Live-Canvas Co-Creation）

- **AI Copilot 同屏抽屉**：废除传统“进入 Agent 就卸载几何画布”的割裂设计，引入同屏可折叠的 AI 抽屉组件 `apps/web/src/components/agent/CopilotDrawer.tsx`。状态栏提供 `✨ AI 助手` 停靠展开按钮，支持边查看/旋转画布边与智能助手自然语言对话，画布绝不卸载。
- **画布实时 Ghost 幽灵草稿预览（Ghost Mode）**：2D 画布与 3D 场景实时以半透明蓝色 `#3d5a80`、脉冲虚线及徽标呈现待确认的新增草稿图元，指针事件直通底层，用户可自由漫游平移或 360° 旋转视角全方位检视草稿几何质量。
- **悬浮确认横幅与双通道快速动作**：在画布正上方浮现胶囊悬浮横幅，动态统计草稿图元数并提供 `[✓ 确认写入 (Enter)]` 与 `[✕ 放弃草稿 (Esc)]` 快速操作；全局快捷键支持非输入框聚焦状态下按 `Enter` 键单步事务合并入库（支持单步 Ctrl+Z 完整撤回）或按 `Esc` 键静默打回丢弃草稿。

### 5. 画布右键上下文菜单与双击内联重命名（Context Menu & Inline Renaming）

- **画布图元原生风格上下文菜单（Context Menu）**：在 2D/3D 画布图元上右键单击，在光标位置弹出微拟物浮动菜单，包含图元类型徽标、6 种常用调色板快速改色、`[✏️ 重命名 (F2)]`、`[👁️ 隐藏/显示]`、`[🔒 锁定/解锁]`、`[🔍 查看从属依赖拓扑]`，以及红底危险操作 `[🗑️ 级联删除 (Del)]`。
- **画布空白处上下文全局菜单**：在画布空白背景处右键单击，提供 `[↶ 撤销 (Ctrl+Z)]`、`[↷ 重做 (Ctrl+Y)]`、`[📐 绘制点 (P)]`、`[📏 绘制线段 (L)]`、`[⭕ 绘制圆 (C)]` 及 `[📋 全选图元 (Ctrl+A)]`。
- **双击与 F2 原位内联重命名（Inline Renaming）**：双击画布图元或按 `F2` 键原位展开内联输入框，自动全选内容，支持重名冲突与非空校验（红色气泡提示），按 `Enter` 提交保存入库，按 `Esc` 或失焦取消。

### 6. 工作台现代极简布局与防挤压重构

- **单行紧凑顶栏与功能区高亮**：顶栏精简至 40px，文件命令、设置与 `Ctrl+K` 模糊搜索面板紧凑整合；Ribbon 功能区激活工具添加强高亮轮廓与下划线。
- **桌面工作台侧栏一键折叠**：底端状态栏提供 `[◀ 左栏]` 与 `[右栏 ▶]` 折叠药丸开关，支持快速收起左右侧栏，将桌面有效作图视口面积释放至 80%+；2D 画布由定高改为 Flex 自适应撑满。
- **上下文智能指针与手势自适应**：3D 视口左键命中自由点/手柄直接拖拽，左键拖空白处或右键拖动自适应旋转视角，全状态下按 `Esc` 均可快速退回选择模式；状态栏在大屏下启用单行防挤压布局，防止文案换行挤压画布高度。
