# MathCanvas 4.2.0

**发布日期：** 2026-11-04

- **属性检查器**统一了属性分组、字段、读数和操作按钮。拖动右栏左边缘调整宽度，双击恢复默认。键盘聚焦分隔线后可用左右方向键调整。平面几何、立体几何和工程制图共享这个设置，重启后会恢复上次宽度。
- **平面绘图**按实际显示的画布坐标确定直线与圆的落点。靠近已有点或曲线时，吸附指示、预览和最终落点使用相同的位置。
- **立体动点**可以按住圆轨道上的点直接拖动，点沿屏幕中可见的轨道实时更新。松手后可一步撤销。属性栏滑轨覆盖完整圆周，并提供四个快捷角度。
- **右键菜单**在平面和立体图元上提供改色、重命名、隐藏、锁定、依赖查看和级联删除。菜单支持方向键导航，并会避开窗口边缘。

Windows x64 可选择 MSI、NSIS 安装包或免安装程序。免安装程序已在 Windows 启动并确认窗口响应。
