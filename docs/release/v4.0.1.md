# MathCanvas v4.0.1

**发布日期：** 2026-10-20 ｜ **类型：** 补丁版（v4.0.0 → v4.0.1；**不改契约、纯增量** —— 读得更多、判得更多、文档与门禁对齐）

## 这一版改了什么

v4.0 是跨大版本（题面读入 / 解析式构造 / 空间原子动作 / 核验判据四条主线，见 [v4.0 发布说明](v4.0.md)）。**v4.0.1 把 v4.0 之后十余轮维护批次收进一个可下载的版本**，主题只有一个：**让题面读得出来、让条件判得出来，并且读不出的不许消失**。

### 1. 题面读入（解析器）

- **命名圆锥曲线**：`椭圆C：x²/16+y²/4=1` / `抛物线C：y²=4x` / `双曲线C：x²/4−y²/9=1`（曲线名 + 标签 + 全角冒号）；根因是后缀守卫把标签冒号当点名尾巴，修法是给六条曲线读取器开**窄开关**，比例写法 `AE:AD=2:5` 仍被原守卫挡住。
- **函数式抛物线**：`y=x²/4` / `y=2x²` / `x=y²/4`（**平移过的** `y=x²/4±1` 明确不认）。
- **圆的一般方程**：`x²+y²−4x+2y−4=0` ⇒ 圆心与半径；右端非零也收，半径平方不为正（点 / 虚圆）不认。
- **曲线过点**：`双曲线过点 A、B` ⇒ 每个点名各一条 "点在曲线上"。
- **直线的一般式**：`3x+4y+15=0` ⇒ 斜率与截距；**只收右端为 0**，不替题面移项。**直线写在曲线前面**（`直线 … 与椭圆 …）也收，桥接段必须带曲线名。
- **链式等号**：`AB=AC=AA₁` 读成相邻两段各一条等长；带数值时链上每段各一条定长。
- **长度写成"的长度 / 的长"**：`线段AB的长度为3` / `AB的长为3`；`弧 AB 的长` 是**弧长**，不混。
- **点在段上的语序**：`AC 上一点 D` / `在线段 AC 上取一点 D` / `点 D 在线段 AC 上`；`直线 AC 上一点 D`、`射线 AC 上一点 D`、`AC 的延长线上一点 D` **明确不读**。
- **中线**：`AD 是 BC 边上的中线` ⇒ `D` 是 `BC` 的中点（`AD 是 △ABC 的中线` 不说哪条边 ⇒ 不猜）。
- **焦点 + 离心率** ⇒ 曲线的参数（中心在原点 + 焦点在坐标轴上 + 离心率；四条边界一律落未核验）。

### 2. 核验判据（新的判据族）

- **实体标量尺寸 `solidDimension`**：圆锥 / 圆柱（半径、高、母线、底面积、侧面积）、正 N 棱锥（底边长、底面周长、底面积、侧棱长、高）、球（半径、表面积、体积）、长方体的外接球 / 内切球半径。判据从**图元或坐标**量，不读题面自报数；闸门很窄（有对应实体动作**且**题面真的读出这类尺寸，否则不启动核验）。
- **一般多面体**：体积（散度定理）、表面积；**内切球半径解球心**（残余含"各面是否真的与球相切"）、**外接球半径**最小二乘（残余含"顶点是否真的共球"）—— 少了这两项，最小二乘总能凑出一个像模像样的半径。
- **三角形的心**：角平分线（两角相等 **且** 在角内部）、内心（到三条**线段**等距 —— 量直线会被旁心冒充）、重心、垂心、旁心（三个之一）、外心。**顺带收紧**：`O 按原点` 那条解析几何约定不再对这些"题面自己定义的点"生效。
- **圆上的度量**：弦心距、弧长（只按劣弧；「优弧」不读）。
- **中位线**：存在性地判"两端各是某两条边的中点"，不猜是哪两条边。

### 3. "读不出"也不许消失

十几族**没有判据**的条件现在会如实落进未核验、并给出**具体理由**（不等式、`≌∽`、直径、交于点、重心垂心、弦心距、弧长、轴截面、展开图、球的尺寸、棱数、仰角俯角、坡度…）；其中 6 族后来补上了真判据。顺带修掉一条**假义务**：`|AB|=2|AC|` 曾被读成"AB 长 2"。

**确认面板**也补了一处：`diagramVerification === undefined`（没有任何一条题设被核验）此前与"核验通过"在界面上看起来一样，现在会显式说清"这一轮没有题设核验报告"。

### 4. 文档

`docs-consistency` 由 4 条扩到 7 条（版本真值 / 状态快照唯一 / CHANGELOG 不落后），并全部做过**变异验证**；`README` / `feature-catalog` / `project-progress` / `current-status` / `CHANGELOG` 按"当前状态唯一"的规矩重新对齐（`current-status.md` 顶部新增「现状总览」，把"已完成 / 仍未做 / 待拍板"一次列清）。
