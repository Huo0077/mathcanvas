# MathCanvas v3.0.1

**发布日期：** 2026-10-01 ｜ **类型：** 补丁版（在 v3.0.0 之上）

## 这一版改了什么

1. **立体几何：三色旋转环默认不显示**（用户口径"把这个太空环删掉"）。画布「3D显示控制」新增**「旋转环」**开关，**默认关**：关着时选中恰好一个可转对象也不建环、`data-rotation-handles` 读 0、枢轴与半径读数一并清空（不留"看不见却能转"的隐形手柄）；要拖着转时点开，15° 吸附、按住 Alt 不吸附、一次拖动一步撤销全都一字未改。偏好存本机（`mathcanvas:3d-view`），不写文档、不进撤销历史。
2. **z=0 网格"无限延伸"**（用户口径"我要的是网格无限延伸的感觉"）：覆盖范围按**可见地面脚印**（视锥 9 条取样射线与 z=0 求交）倒推档位；远处的淡出用**顶点色**烘进几何 —— 内圈格线色、到边界正好是纸色（等于化进纸里），所以那块方块的直边永远看不见。另把格线色提到 `#cdd8e6` / `#aebccf`（与 `tokens.css` 同源，平面几何的画布格线一并变清楚）。读数新增 `data-grid-fade` / `data-grid-ground-reach`。
3. **不含"暖纸（淡黄）配色"**：那套当天做过、当天按用户口径**"太丑了，还是回退吧"整体回退**，改动留在仓库的 `git stash` 里，随时可 `git stash pop` 取回。
