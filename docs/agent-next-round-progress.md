## 每完成一个区块的更新模板

记录日期、commit、本区块 RED 的**实际失败原因**、GREEN 测试的**确切命令与计数**、适用平台、题型矩阵增加/减少的分子分母、尚未覆盖项、CLI/桌面/浏览器/付费运行是否真实发生；同步现状/能力/门禁/归档/README，检查 BOM、控制字符和末尾换行；仅暂存本块文件、提交、`git push origin main`、`git ls-remote origin refs/heads/main` 与本地 SHA 一致。**环境失败/未授权付费/未运行 Lean 不写“通过”。**
