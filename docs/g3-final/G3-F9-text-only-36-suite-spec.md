### 两个候选路线的取舍

1. 仅测23：最快，但不能叫36题，也会让立体覆盖降至5题，难与旧36规模/构成对比。
2. **采用23+13新独立版本**：原23个冻结 prompt、输入 hash 和合同作为候选沿用；新增8道高考立体+5道联考立体无图真题，独立审查后再批准新集。保留规模与4类各9题配额；这是选定路线。
3. 给13个有图题删“如图”或让模型猜图：禁止，这会改变题意、污染黄金合同，也违背跳题要求。

## 输入与来源准入（逐题人工可复核）

- 原始题面必须是可追溯、可独立核验的真题，保留考试名称、年份/场次、题号、来源页面或试卷文件及题面 SHA-256；题图缺失、图片中含定义条件、引用图中点位、需要观察原图才能确定拓扑/分支/方向/量值的，一律不进本集。
- `inputMode=text_only` 只是旧题集标签，不等于“图像可唯一重现”。旧23题也需重新审查是否有隐藏图示依赖；发现任何一题不满足则退出候选，并以**同来源类别**的无图题补位，不能改 prompt 越闸。
- 文本可以留下几何对称、镜像、动点等多解；只在原文允许且合同显式接纳所有合法分支时入选。几何实现需要选择展示视角不是题意缺失；不得把视觉风格自由度误判为图形无解。
- 保留原题表述；附加“请画图”只能作为**统一测试指令**，不可注入参考坐标、推导答案、隐含补充条件。每题至少有可绘制的几何对象、关系和可独立测量的合同检查；单纯答数值不构成作图成功。独立审查至少两人/两轮，记录歧义、分支、来源、绘制要素与否决原因。
- 自编的 `explicit-solid-acceptance-40` 是离线集，不能冒充真实试卷题；不能用13道同义改写/相同原题的重复计数凑数；测试时向模型仅提供公开题面+统一画图指令，不给隐藏合同、预期坐标或审查意见。
