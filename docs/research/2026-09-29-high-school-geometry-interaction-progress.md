## 最新完成模块：立体教学线型（已验证，已上传 GitHub）

- 新增的空间线段、空间直线、空间射线及空间棱支持文档级实线、虚线和点线。沿用 `PrimitivePresentation.style.dash`，不改 `.mgeo` schema；`threePrimitives.ts` 给明确的虚线/点线材质计算线距离，选择高亮时线型不丢。
- 检查器对这些 3D 图元显示「教学线型」及说明；已有「隐藏边」仍是**视图开关**，不把自动遮挡虚线写成教师手工设置的图元样式。已有截面/交线预览有独立颜色和渲染路径，本轮没有改其语义。
- 完整验证（本轮最新）：`npm run typecheck` 成功；`npm test -- --maxWorkers=3` **265 个文件、3055 项通过、1 todo、0 失败**；`npm run lint` **0 error、13 warning（仓库既有警告）**；Web 工作区构建成功（入口 1694.22 kB，存在已有的大 chunk 警告）；所选 7 个 3D e2e spec **44 条通过**，包含直接作图、常用立体、3D 拾取、旋转环、相交预览、旧棱柱文件加载和教学虚线。首次整库测试的 2 条旧断言仍以旧 `4×4×2` 正方体算截面/体内范围；现已按新 `4×4×4` 几何修正并复跑整库绿灯。

## 尚需推进的既定范围

1. 3D 画面清爽度：选中直线/线段时的三色旋转环会遮挡教学虚线，后续需提供**可见且不改几何的视图控制**；仍要保留需要旋转时能使用手柄。补齐悬停落点的目标名称/世界坐标提示，并检查点名遮挡与教学角/垂直标记。
2. `e2e/high-school-geometry-tasks.spec.ts` 六类代表题：三/四棱锥高线与截面、斜棱柱、异长长方体、圆锥截面、点线面关系、旧文档恢复；逐题验证几何、依赖、保存、撤销，不用“看着像”代替数学判断。教师/学生实际试用还没做。
3. 更灵活的实体底面输入、拖放顶点/高度手柄与关联拉伸未交付；现有「使用选中面作底面」会**独立复制当时的坐标**，不追随原面更新。
4. 球体/球截面、截图生成可编辑数学图、平面/函数的逐题补缺和 HTML/GGB 导出属于单独后续方案，当前不能算完成。
