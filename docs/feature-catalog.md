# MathCanvas 功能目录

这份目录记录当前可用能力、已确认的下一阶段能力以及明确的限制。它是产品说明，不替代 DSL 类型和测试。

## 当前已实现

- React/Vite 工作台、SVG 画布、Algebra View、选择、删除、锁定、分组、对齐和可见性控制。
- 点、线、线段、射线、折线、圆、圆弧、抛物线、椭圆、双曲线和函数图像的基础创建或属性编辑。
- 颜色、填充、线宽、透明度、虚线等公共样式编辑。
- 直线、圆、圆弧、圆锥曲线和函数的采样渲染。
- 参数滑块、表达式依赖 DAG、约束重算、撤销/重做和 `.mgeo` 保存/恢复。
- 直线—直线、直线—圆、圆—圆及采样曲线交点的分类、更新和异常回滚。
- SVG、CSV、PNG 和 `.mgeo` 导出，以及浏览器级回归验证。
- 可编辑函数公式框与计算器式公式键盘，支持 `e^x`、`sin(ln(x))`、绝对值、反三角、双曲函数和带底数的 `log_b(x)`；函数按钮按光标位置插入，不再使用独立的函数预设选择器。
- 参数动态演变控制，支持播放、暂停、停止、循环、单次和往返模式；动画预览不逐帧污染撤销历史。
- 属性检查器按当前图元特异化显示，公共样式与几何关键属性分组呈现；中间画布会横向填充可用工作区，默认以 `(0, 0)` 为中心并支持鼠标中键拖动或 `Space + 左键拖动` 平移。
- 函数公式编辑框中的 Backspace/Delete 保留文本编辑行为，不会触发全局删除图元；画布悬停显示当前坐标。
- 函数采样遇到无定义值或疑似渐近线跳变时分段绘制，不会将无定义区间显示为竖直连线。
- 函数公式使用编译缓存；绘图、属性值域、导出和采样交点使用带细化上限的自适应采样。
- 函数内核支持一阶和二阶中心差分；无定义邻域返回明确的非有限结果，不继续计算伪导数。
- 函数分析内核支持数值零点、局部极值和拐点检测，并明确标记近似结果。
- 导函数图元保存来源函数 ID、阶数、定义域和采样参数；来源函数更新时由 Scene Graph 自动重算。
- 切线、法线和割线图元保存来源函数 ID 与计算参数，支持近似/无定义状态并随来源函数重算。
- 积分区域和分析结果集合可保存来源函数、计算区间、采样参数、结果点及诊断状态。
- 微积分属性面板可创建导函数、切线、法线、割线、积分区域和分析结果；画布展示曲线、区域和零点/极值/拐点标记，Algebra View 保留稳定对象 ID。
- P6 内核已具备不可变 `Vector3` 运算、三点定平面、射线拾取平面和二面角基础计算；Three.js 运行时依赖已加入 Web workspace。
- P6 DSL 已支持参数化立方体、棱锥、圆柱和圆锥，并保持 `schemaVersion: "0.1"` 与旧 2D `.mgeo` 解码兼容。
- P6-3 已接入原生 Three.js 3D 场景：参数化立方体按 DSL 尺寸和原点生成网格、边线、灯光、网格和坐标轴，并在 `geometry3d` 工作区提供创建入口；WebGL 不可用时显示明确降级状态。
- P6-4 已增加棱锥、圆柱和圆锥的参数化 Three.js 网格与工作区创建入口，四类实体均保留稳定 DSL ID、样式和选中高亮映射。
- P6-5 已支持 3D 画布左键旋转、中键平移、Shift+左键平移、滚轮缩放、视角重置和基于 Three.js Raycaster 的空间拾取。
- P6-6 已支持透明面、隐藏边虚线、法向量箭头和实体选中高亮；三类显示状态均可从 3D 画布控件切换。
- P6-7 已支持保存来源实体 ID 与平面参数的截面对象；平面与立体棱求交生成截面点，来源实体变化后由 Scene Graph 自动重算，无交集时显示明确状态。
- P6-8 已支持立方体六面确定性展开布局、展开/折叠动画进度和画布控件。
- P6-9 已接入二面角测量显示，复用归一化法向量夹角内核，并明确展示示例法向量来源。
- P6-10 已将立体几何原点、尺寸、底面、高度、半径和分段数接入属性栏与 Scene Graph patch 校验；Three.js 使用隔离挂载点保留 React 控件、重置按钮和降级状态。
- P6 v2-1 已增加点驱动三维 DSL：空间点、直线、线段、射线、平面、空间圆、棱、面和多面体支持稳定引用、退化校验与 mgeo round-trip；旧 2D 和四类参数化实体仍可读取。
- 新建点自动使用 A/B/C 等课堂标签；选择两个点后可创建保存点 ID 引用的动态线段连接。
- 点可绑定直线、线段、射线、折线、圆、圆弧或函数路径，并可记录参数域轨迹。
- 交点集合会显示所有数值交点位置；选中椭圆、双曲线或抛物线时画布标出中心、顶点和焦点。
- 抛物线连接必须提供第三点或完整顶点模型，两个点不会被自动猜成抛物线。

### P6 v1 的边界

当前四类参数化实体是可用的教学工作区基线，不代表三维建模能力只限于立方体、棱锥、圆柱和圆锥。它们目前仍以模板入口为主，点、棱和面的通用创建与编辑将在 P6 v2 实施。

## 下一阶段功能

### 三维通用构造（P6 v2，已规划）

- 点是三维构造的关键属性，支持 `x/y/z` 编辑、课堂标签、网格吸附、点在线/面上绑定和派生点来源。
- 选择两个点创建直线、线段或射线；选择三个不共线点创建平面；选择闭合点链或面集合创建任意多面体。
- 支持三棱柱、四棱柱、棱台、组合体和任意闭合多面体；参数化模板可拆解为点、棱、面后继续编辑。
- Algebra View 展示顶点、棱、面子树；点移动自动更新拓扑、截面、展开图和测量结果。
- 支持空间拾取、辅助平面、共线/共面/平行/垂直约束、长度/面积/体积/距离/角度测量和来源解释。
- 支持通用截面、展开/折叠、二面角、法向量、隐藏边、透明面、选中高亮和数值失败诊断。

详细设计与切片验收见 [`2026-09-14-point-driven-3d-geometry-design.md`](./superpowers/specs/2026-09-14-point-driven-3d-geometry-design.md) 和 [`2026-09-14-point-driven-3d-geometry.md`](./superpowers/plans/2026-09-14-point-driven-3d-geometry.md)。

### 函数

- 更丰富的公式键盘分类、符号模板和可选参数输入。
- 用户表达式与复合表达式，例如 `exp(-x^2) * cos(2*x)`、`log(x + 3)` 和参数化的 `a*sin(b*x+c)+d`。
- 定义域校验、采样密度和视口重采样。
- 函数的切线、割线、导数和积分标记作为派生对象。

### 点、标注和路径

- A/B/C/D 等可编辑标签、点的坐标显示、特征点自动标注和自定义注释。
- 点绑定自由坐标、线段/圆锥曲线/函数路径或其他图元的派生特征。
- 动点、轨迹采样、轨迹显隐和轨迹清除。
- 通过已标记点创建线段、直线、射线和折线；移动端点后连接关系持续有效。
- 抛物线连接必须补充顶点、轴向、焦参数或第三点等额外约束。

### 动态与分析

- 参数滑块、播放、暂停、停止、循环、单次和往返模式。
- 交点列表、交点坐标、解索引和切线交点状态。
- 圆锥曲线的中心、顶点、焦点、准线、离心率、渐近线和面积/周长等关键属性。
- 分析面板显示斜率、截距、定义域、值域、对称性和采样状态。

## 明确限制

- 两个点本身不能唯一确定一般抛物线；产品不会悄悄猜测一条抛物线。
- 采样函数和曲线的交点是数值近似，必须显示“采样/近似”状态，不能伪装成符号精确解。
- 极点、渐近线和无穷远交点不作为普通有限坐标点写入 `.mgeo`。
- 动画帧不逐帧产生撤销记录；只有停止、确认或手动改值才提交文档。
- 任意 JavaScript 表达式、网络加载脚本和不受限用户代码不属于函数输入能力。
