# 人工验收走查手册（一步一步）

> **这份手册是给你（人）用的，不是给机器用的。** 机器能做的验收已经全在自动门禁里了
>（`npm test` / `npm run test:e2e` / `npm run test:rust` / 四条文档门禁）；**这里剩下的三件事机器做不了**：
> ① 人看图判断"像不像、对不对"；② 管理员权限装 MSI；③ 付费调用真实 provider。
> 每一项都写清了：**点哪里 → 看什么 → 怎么算通过 → 记到哪**。

## 任务 A：教师/学生看图走查（V0 出口唯一缺项）

**它的目的**：机器只能证明"数值关系对"（例：读回真实落盘坐标、自算点积 = 0），
**不能证明"这图像不像课本上的图"**。这一步就是补那半。

### A.1 每一步都一样的操作（先记熟这四步）

1. 打开应用 → 右侧 **Agent 工作区** → 在 **`对话输入`** 框里**粘贴**下面某一题的题面 → 点 **`发送`**；
2. 等它出图（右侧出现草稿预览，面板里能看到 **`题设核验`** 那一栏）；
3. **看图**（画布上）→ 按 A.3 的清单逐条判断；
4. 点 **`确认改动`**（或 `确认并提交`）→ 图进入画布 → **按一次 Ctrl+Z** 看是否一步退回；
5. 把结论填进 A.4 的表（**通过 / 不通过 + 一句话理由**）。

### A.2 六道题（覆盖四个家族，都是自动用例里的原题面，照抄即可）

| # | 家族 | 粘贴这一句 | 你该看到 |
|---|---|---|---|
| 1 | 立体·自由顶点 | `在三棱锥D-ABC中，AD⊥平面ABC，自由点D，画示意图` | 三棱锥；D 由见证搜索定；题设核验里有 `AD⊥平面ABC` |
| 2 | 立体·直棱柱（撇点名） | `在三棱柱ABC-A′B′C′中，AA′⊥平面ABC，画出这个三棱柱` | 上下两个三角形，顶面顶点带 `′` |
| 3 | 立体·菱形底面 | `在四棱柱ABCD-A′B′C′D′中，底面ABCD是菱形，AA′⊥平面ABCD，画出这个四棱柱` | 底面四边看着等长；四条侧棱竖直 |
| 4 | 立体·斜棱柱 | `在斜三棱柱ABC-A′B′C′中，AB=2，画出这个斜三棱柱` | 侧棱**明显斜**（不是竖直） |
| 5 | 平面三角 | `在三角形ABC中，AB⊥AC，画示意图` | 直角在 A；角看着是 90° |
| 6 | 圆锥曲线 | `椭圆 x²/9+y²/4=1，画示意图` | 横长竖短的椭圆（x 半轴 3 > y 半轴 2） |
| 7 | 函数图像 + 切线 | `画出 f(x)=x³−3x 的图像与它在 x=1 处的切线` | 曲线在 x=1 处**水平**（因为 f′(1)=0） |

（第 7 题是最容易一眼判断对错的一道：切线如果是斜的，就是错图。）

### A.3 每道题都问自己这 6 个问题

1. **形状对不对**：顶点数、底面边数、有没有撇号顶点？跟题面说的一样吗？
2. **关系对不对**（肉眼）：该垂直的看着垂直、该平行的看着平行、该斜的明显斜？
3. **切线/曲线对不对**（第 6、7 题）：切线水平吗？椭圆是横长还是竖长？
4. **标签清不清**：顶点名能看清、跟题面点名一致（`A′` 不是 `A1`）？
5. **面板说了什么**：`题设核验` 里每条是不是 `passed`；若有 `未核验`，**那句话是不是确实读不出来**（读不出来是对的，别当成 bug）？
6. **提交与撤销**：`确认改动` 后图进画布；**一次 Ctrl+Z** 退回；再 Ctrl+Z 没有第二步？

### A.4 记录表（抄到你的笔记里，或直接回报给我）

| # | 通过? | 不通过的那一条（哪一问） | 一句话描述你看到的 |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| … | | | |

**只要有一道"看着明显不对"就记下来** —— 那是我下一轮要修的东西；**"看着对"也要记**，
因为 V0 出口要的正是"人确认过"这句话。

## 任务 B：管理员 MSI 安装验收（要管理员权限）

> NSIS 那半此前已在本机走完一圈；**MSI 这一半必须管理员**，所以我做不了。

1. 右键 `...\bundle\msi\MathCanvas_3.2.0_x64_en-US.msi` → **以管理员身份运行**（或在 UAC 弹窗点"是"）；
2. 按向导装完（默认路径即可）→ 记下它报的安装目录；
3. **开始菜单**里找 `MathCanvas` → 点开 → 应用能起来（这是"装完能启动"）；
4. 关掉应用 → **设置 → 应用 → 已安装的应用** 里找到 `MathCanvas` → **卸载**；
5. 卸载后检查三件事：
   - 开始菜单里那条**还在不在**（应该没了）；
   - 安装目录**还在不在**（默认应该被清掉）；
   - 桌面/任务栏有没有残留图标。
6. 记录：安装路径、能否启动、卸载是否干净、有没有报错弹窗。

**通过标准**：装得上、起得来、卸得掉、没有残留报错。
**注意**：卸载**不会**删你的工程数据（那是 SQLite 存在用户目录里的）—— 如果它删了，那才是问题。

## 任务 C：真实 provider 付费基线（**要你明确同意付费**）

> 我**不会**替你触发任何付费调用。这一步全部由你在界面上确认。

### C.1 先配好 profile

1. **`设置`** → **真实 provider 评测**（或"模型配置"）→ 新增/编辑一个 profile：
   填 **base URL**、**模型名**、**API Key**（Key 存进凭据库，**不出本机**）；
2. 回到 Agent 工作区 → 确认右上角/状态区显示的**当前 provider**就是你配的那个。

### C.2 跑两个入口（**两次都要你点确认**）

| 入口 | 位置 | 它会问你什么 | 大约花多少请求 |
|---|---|---|---|
| **agent 工具环** | 设置 → 真实 provider 评测 → **agent 工具环** | "将发 **8 题 × 3 轮 = 24** 次请求，确认付费？" | 24 |
| **题集 planning** | 设置 → 真实 provider 评测 → **题集 planning** | "将发 **3 次**请求，确认付费？" | 3 |

### C.3 记哪些数（面板会直接打出来）

- `pass@1` / `pass@3`（工具环）、工具选择正确数、工具错误数、`attempts`；
- `planned / clarification / rejected / error` 各几条（planning 轴）；
- **平均延迟 ms**；
- **成本**：现在两轴都显示 `not measured` —— **这不是 bug**，是因为**仓库里没有价目表**
  （没有"每百万 token 多少钱"这份数据，我们就不编一个数字）。你有两个选择：
  ① 把价目表给我（模型名 + 输入/输出单价），我接进去；② 就让它继续显示"未测"。

### C.4 记录

题号区间、每轴的计数、延迟、有没有超时/截断、**大致花了多少钱（你从服务商后台看）**。

## 任务 D：真桌面里跑一次自动 Lean（**入口已于 2026-10-10 做好，随时可做**）

**入口**：设置 → 实验性功能 → **形式证明导出**（默认关）。打开之后，跑完作图、题设也核验过了，
系统会顺手问一次"题面里那一条能形式化的目标能不能证"，并把结果摆在**确认面板的「形式证明」那一段**上：
**结局**（证了没有）、**正文是谁给的**（系统按类给的 / 模型写的）、**系统替你做了哪些选择**。
那一段还带一句必须说的边界：**原题其余题设没有进命题**，所以那是那一条受限目标的形式证明，**不等于整题已证明**。

**注意**：只有**桌面版**能真跑（浏览器里如实显示"这台机器跑不了"）；开关与面板都不影响作图与人工确认。

跑一次之后要核对的：面板/草稿里出现的那条证明记录（证成 / 未证 + 原因 + 正文来源），
以及"没配工具链时它是否如实说'这台机器跑不了'"。

## 已知边界（**这些不是 bug，别记成失败**）

1. ~~**画布顶点标签与核验器用的 `vertexNames` 可能错位**~~（**2026-10-10 已修**）——
   原来"核验通过"可能指的是另一个顶点（画布上的 `A` 是顶点，而面板说的 `A` 是底面那个点）；
   现在**画布标签就是题面点名的那些名字**，走查时按题面点名读图即可。**若仍看到对不上，那是新问题，请记下来**；
2. **"在上方"这类写法会如实拒绝**（不做未核验放行），不是失败；
3. ~~**球的状态词表**（"存在但主张不成立"怎么措辞）待裁决~~ —— **2026-10-10 已裁决**：那种情况现在读作「**不再成立**」（第五个词 `stale`），"真的没有这种球"仍旧读作「不存在」——**两句话不再混用**，你不用再替我们区分这两种情况；
4. **模板实体不进原文核验**（例：`添加立方体` 那条路径）；
5. **草图不唯一时**系统会挑一个"符合直觉且满足题设"的（这是你早先定的口径），
   面板里会把"系统替你选了哪些值"列出来 —— **那不是错**。
