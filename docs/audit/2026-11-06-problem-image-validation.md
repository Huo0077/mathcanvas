# 题图识别实测与修复记录

2026 年 11 月 5–6 日，用 MathCanvas 已验证的 DeepSeek Flash 配置首读 32 道此前未测的公开真题，每题一次。先对照原图核对题干、公式、条件与答题所需图表，再在本地浏览器回放真实模型返回，检查能否展示、是否要求核对、交给 Agent 的内容是否完整。用户提供的四棱锥第 17 题和直三棱柱第 15 题另测，关键题干和点名可读，配图定位及虚实线读数仍有偏差。

## 三批首读结果

| 批次 | 首读与交接 | 复现的问题 |

## 修复与复测

| 实际案例 | 修复后的行为与证据 |
| --- | --- |
| 八省联考第 18 题把 `M₀(1,4)` 读成 `M₀(0,4)` | 具名坐标进入复核。重新框选局部后读出了 `M₀(1,4)`，读数供用户修改题干。整图仍可能错读 |
| 2025 新课标Ⅰ卷第 6 题漏掉向量端点与方向，第 17 题有无效配图框 | 需要向量方向时要求核对或补充端点。坏框只影响该读数的定位，题干和读数文字保留 |
| 2026 全国Ⅰ卷第 8 题把补集当作并集，全国Ⅱ卷第 16 题返回非法 JSON | 针对两种符号的开口方向补充识别提示，可疑符号进入复核。修复后的整图与局部请求读出了补集。旧 JSON 可用受限的定界符转义恢复，新请求可正常解析 |
| 2024 适应性测试第 17 题多报 `C₁D` | 点名和数值保留为参考。虚实线及连接关系须逐条确认才随题发送 |
| 2024 全国甲卷理科第 7 题漏读 A–D 图像 | 四项图形描述可编辑，确认后才可发送。新请求返回四项描述，部分对称性描述仍有错误，浏览器回放验证了修正与确认路径 |
| 2024 新课标Ⅱ卷第 14 题的数字框错行 | 能定位规则的横竖格线时，按原图格线对齐读数框。旧返回和新请求均复测了数字 16 的框是否覆盖实际数字。无法可靠定位时保留数值及可恢复的行列，隐藏不可靠的框 |

最后一轮通过 80 项定向测试、14 项浏览器回归和类型检查。浏览器回归覆盖第三批的 10 份返回、最新提示下两份新模型返回，以及仓库中的两项题图流程用例。直三棱柱用例走到核验和提交，公开题图回放检查到 Agent 收题。真实模型仍会漏读或误读图形。可见格线校正只处理可可靠定位的规则横竖方格，图形选项与题设的数学正确性仍需单独核对。
