# Agent 数学答复与矩形折叠核验修复

日期：2026-11-02。范围：数学结果从确定性求解、规划、运行到持久化和展示的完整通路。

## 用户案例与行为

输入：矩形 ABCD，AB=4、BC=2，沿 AC 折起 △ABC，使平面 ABC 与平面 ACD 垂直；证明 BD⊥AC，并求折后 BD。

该题第一问不成立，第二问有确定答案 `BD=2√85/5≈3.687817783`。系统现在正常完成只读答复，分别交付两问，并解释折痕上的投影不变；不再把已得出的结论包装成 `needs_more_information`。第一问不生成证明草稿。

只有求长度时，仍提供隔离的折叠草稿，计算结果随预览一起显示，确认提交后仍保留答案。缺折角时继续等待补充信息，不默认 90°。

## 合同与边界

- PlanEnvelope 的 plan 分支新增可选 `answer`，保持既有 schemaVersion；解析器显式校验其字符串类型及长度。旧计划可继续省略该字段。
- `RectangleFoldSolution` 新增 answer 分支；clarification 仅承载需要用户回答的折角问题。条件矛盾单独分类，不生成几何结论。
- 核验仍是受支持题族的坐标核验，不等同于形式证明。未构造的辅助点明确标记未核验，本轮未新增通用垂足构造器。
- 目标读取支持线段垂直和线段长度；没有扩大到任意数学目标。折前、折后使用各自点表；连续两折不套用单折的解析长度公式或投影论证。
- 精确根式仅由已知的小整数边长（1～100）以及单次 90° 折叠公式推导，或用于折前的另一条对角线；其它情形保留数值近似。不会用浮点近似猜测精确常数。
- 条件一致性检查覆盖本次矩形边长与边比缺陷，不宣称完成所有几何题设的全局可满足性判定。
- 新增格式化只生成 React 文本、strong、code 节点，不解析或注入 HTML。
- 本轮验证使用离线与模拟模型路径，不发起真实 provider 调用，也不代表模型泛化质量评估。
