## 2. 独立数学推导

取 `A₂=(0,0,1)`、`C₂=(2,2,3)`、`D₂=(0,2,2)`、`B=(2,0,0)`、`B₁=(2,0,4)`。

用归一化线段参数 `t∈[0,1]` 写 `P=B+t(B₁-B)=(2,0,4t)`。铰链方向 `v=C₂-A₂=(2,2,2)`。将相关向量投影到与铰链垂直的平面：

- 固定侧 `d=D₂-A₂-(d·v)v/(v·v)=(-1,1,0)`。
- 动点侧 `w(t)=P-A₂-((P-A₂)·v)v/(v·v)=((5-4t)/3,-(1+4t)/3,(8t-4)/3)`。

因此

`d·w(t)=-2`，`|d|²=2`，`|w(t)|²=(32t²-32t+14)/3`，

`cosθ=-√3/√(16t²-16t+7)`，`cos²θ=3/(16t²-16t+7)`。

分母 `16t²-16t+7=16(t-1/2)²+3`，在闭区间 `[0,1]` 上最小为3、最大为7。由于 d·w(t) 始终为负：

`cosθ∈[-1,-√(3/7)]`，从而 `cosθ< -1/2=cos120°`。

所以120°不可能出现。这里的负号对应二面角投影方向，不能用角度绝对值替换。若使用实际长度 BP=u=4t，则等价写法是 `cos²θ=3/(u²-4u+7)`，与归一化公式相同，不能混用两组系数。

## 3. 实现与反例

新增 `segment-dihedral-infeasible-3d` 证据：

- 从真实铰链、固定点和 BB₁ 端点重算投影向量及二次多项式，不接受仅抄写系数。
- 显式记录 `parameterDomain:[0,1]`、`sign:"negative"`、`numerator:[3,0,0]`、`denominator:[7,-16,16]`，并与重算结果比较。
- 对凸二次分母计算端点与区间内顶点的真实范围，再判断目标余弦是否落在完整余弦区间之外。
- 仅支持有常数正分子、正二次分母的已声明证据形态；其他非线性形式不冒充已证明。
- 指定 scope 的结构化诊断与禁止伪造 P 同时必需，关键词不能替代。

首次合同把物理长度 BP=t∈[0,4] 的分母 `[7,-4,1]` 与求值器归一化参数 `[0,1]` 混用，正例明确报告系数不匹配。改为归一化分母 `[7,-16,16]` 并显式记录区间后通过；这是参数语义纠正，不是容差放宽。
