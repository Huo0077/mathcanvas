## 2. 数学推导与可执行义务

### GK-P07：最大面积20√5

抛物线 `x²=4y` 上切点 A=(a,a²/4)、B=(b,b²/4) 的两切线交于 `P=((a+b)/2,ab/4)`。令 P=(u,v)，则 `(a-b)²=4(u²-4v)`，面积为

`S=|b-a|·|u²-4v|/4 = (u²-4v)^(3/2)/2`。

P 在圆 `x²+(y+4)²=1` 上，故 `u²=1-(v+4)²`，且 `v∈[-5,-3]`。于是

`u²-4v=21-(v+6)²`，其导数 `-2v-12<0`，所以在整个区间随 v 递减，唯一最大值位于 `v=-5,u=0`。

`Smax=20^(3/2)/2=20√5`。`ob-max-area` 检查实际曲线/圆、切点参数关系、独立叉积面积、期望值及 P=(0,-5)，不接受另一对合法切线代替。

### JT-P03：最小 |DE|=4/3

令 A=(a²,2a)、B=(b²,2b)。AB 经过 (2,0) 给出 `ab=-2`。OA、OB 与 `l:y=x+1` 的交点为

`D=(a/(2-a),2/(2-a))`、`E=(b/(2-b),2/(2-b))`。

令 `s=a+b`，则

`|DE|²=2(s²+8)/(s-1)²`，并且

`|DE|²-16/9 = 2(s+8)²/[9(s-1)²] ≥ 0`。

等号只在 `s=-8` 取得，所以最小值为4/3。取 `a=-4+3√2`、`b=-4-3√2` 即满足 `ab=-2` 与 `s=-8`。`ob-de-min` 检查这些参数、D/E 的真实交点、实际距离和取等条件。

自查补上 A/B 对 AB 的双端点宿主检查：错误 AB 即使也经过 (2,0)，仍被拒绝。原先 |DE|=4 的旧正例已改为最优候选，s=0 的同一普通候选保留在独立负例中，没有删除反例或放宽容差。

### JT-P07：最小 PE·QF=1

椭圆 `x²/4+y²=1`，B=(2,0)。设过 (1,0) 的弦斜率为 k，交点横坐标为 x₁、x₂，则

`(x₁-1)(x₂-1)=-3/(1+4k²)`，`(x₁-2)(x₂-2)=4k²/(1+4k²)`。

由 BP、BQ 与 x=3 的交点计算：

`PE·QF=(3-x₁)(3-x₂)/4 = (16k²+5)/(16k²+4)=1+1/(16k²+4)>1`。

竖直弦 x=1 需要单独处理，此时 `P=(1,√3/2)`、`Q=(1,-√3/2)` 给出 PE·QF=1，故最小值1确实取得，不是有限斜率下的未达下确界。新增 `ob-pq-distinct`，`ob-pe-qf-min` 同时检查实际椭圆、宿主、E/F 与 x=3 的交点、实际点积和竖直取等弦。
