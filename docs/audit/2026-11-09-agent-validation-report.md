## 8. 建议下一轮实施与验收门槛

1. **先修评测口径**：scored分母只从实际可计分对象计算；补correct:null澄清/失败、零分母、不超过100%的测试。新增最终答案字段评分作为新版本，旧口径并列保留，不悄悄改历史成绩。
2. **接通生产语义闭环**：真实题意→逐问目标/必要条件→结构化候选→独立核验→acceptAnswer→UI。保留旧conversation兼容路径，但标明未核验；不允许将空证据包装为已验证。
3. **接入有限核验器**：先覆盖圆锥曲线范围与数值反例、三视图模板和几何量计算。核验只能提供相应级别证据，不把抽样当证明。加入text-198与mm-005真实链路回归，而不只测纯函数。
4. **图像证据门槛与重读**：尺寸/虚实线/选项映射缺失即澄清或预算内局部重读；禁止按选项反向创造条件；验证重读次数上限及失败回退。
5. **修计划格式与引用恢复**：基于当前注册动作自动生成输入样例，统一faces整数索引、alias与vertices约定；工具结果提供合法引用标识，错误引用允许一次有界修复，不能绕过门禁。
6. **再做分层验收**：离线模块+真实coordinator接线测试+AgentRunner/UI路由测试+本50题同口径复测；另选未用于开发的高考/联考图文留出集，冻结材料、模型配置和预算再盲测。单独评分选项、逐问覆盖、条件使用、推导和最终作图。

建议发布门槛：无已知>100%统计错误；生产接线测试能证明核验与澄清实际触发；本轮失败题均有可定位结果；同材料交付率不退化；真实盲测结果单独披露。达不到时可以发布工程能力，但不宣称数学准确率整改已验收。
