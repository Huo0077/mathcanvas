# 多未知折角联立求解

## 目标与入口

接续[翻折完整性与输出链路修复](2026-10-25-fold-completeness-and-output-limits.md)。此前多折叠链只能直接构造每一步角度都已知的情况，单角反求也无法处理多个角同时影响终态条件的问题。

现在 `compilePlan` 在多步翻折中调用 `solver/coupledFolds.ts`，最多联立求解3个未知折角；已有单次翻折仍走原有单角求解。缺失折动作的受支持四边形题可先规范重建底图、分点及折叠链，再进行联合求解。分类器将依赖完整但缺角的链标为 `coupled`，不再一概判为不支持。

## 方法与约束

1. 按折后点名与有向折痕，将计划动作逐一匹配到原文翻折描述。匹配不明确时不猜。题面显式角度固定，其余折角组成未知向量。
2. 选取原始题设 IR 中涉及折后点、角色为 `given` 且判据支持的条件。条件少于未知量时返回 `fold_system_underdetermined`；未核验条件不因为求解而删除。
3. `geometry-kernel/foldSystem.ts` 采用确定性多起点、有限差分雅可比与阻尼最小二乘。每次残差评估都重新执行真实编译器，从最新折后坐标量取终态条件，不把第二折误算在初始图形上。
4. 数值候选先检查局部雅可比秩，再逐个独立重编译，要求 `ok`、非空候选文档与整题核验 `passed` 同时成立。底图条件冲突、漏点、折叠刚性、显式角度及未支持条件仍经过原来的门禁。
5. 试算使用独立 ID 分配器，最终选定候选才在真实草稿上下文中编译。返回真实动作和可重放操作；原输入计划与基础文档不被求解过程改写。

即使模型恰好填了能通过的默认角，也不能据此把欠定系统标成联合求解成功。条件数量与局部秩检查是保守的准入条件；秩不足不能证明数学上的解集维数，更不能证明无解。

## 预算与边界

| 项目 | 默认值 / 行为 |
| --- | --- |
| 未知折角数 | 1–3个，入口要求总共至少两笔折叠；题面已知角不占未知量 |
| 搜索角域 | `[0.00001°, 180°]`，正向按有向折痕定义；不枚举反向或大于180°的未知角 |
| 起点与迭代 | 最多24个确定性起点，每起点最多48次迭代 |
| 残差评估 | 默认1024次，配置硬上限4096次 |
| 墙钟 | 默认1500ms；在评估边界检查，不中断一次已经执行中的编译 |
| 候选 | 默认最多8组，按角向量排序选一组；其余通过整题核验的候选在假设记录中保留 |
| 取消 | 数值内核提供 `shouldStop`，在评估边界退出；未新增跨 Worker 的中断消息协议 |
| 失败 | 区分条件不足 / 数值秩不足、预算或超时未找到、取消、范围不支持、候选未通过全题核验 |

搜索使用题设判据的容差归一化残差；最终仍由原始整题核验决定能否生成草稿。`complete: false` 随结果保留；预览明确说明这是数值见证，不保证枚举全部解，也不是普遍证明。搜索结束无候选只说明预算内未找到，不等于证明无解。

这是在已构造几何上的折角求解，不同时解任意未知底图坐标或尺寸。独立折片的动作若已正确给出，可进入数值求解；缺动作时的规范重建只覆盖现有受支持的依赖链。不支持任意文字题、符号角方程、分段折叠或任意数量的未知角。

## 预览与提交修复

浏览器回归发现：返回画布再进入 Agent 后，组件内的启动标记随重新挂载丢失，同一条待确认消息会被再次启动。快速编译时不易察觉，慢速联合求解会在旧预览还可见时把运行指向新建的空草稿，确认结果因而变成“无需改动”。

`AgentWorkspace` 现在读取消息已有的 `runId`，已绑定运行的消息不再自动重启。组件重挂载回归与浏览器“预览 → 切画布 → 返回 → 确认 → 一步撤销”共同覆盖这条链路。

## 回归依据

- 内核：双变量非线性方程的多分支、三变量联立、缺失与相关条件、非有限残差、预算、取消和超时。
- 真实编译：两折同时调整，三折联立，固定题面已知角，缺动作的四边形规范重建，欠定及恰好通过的默认角，底图冲突与不可达终态。
- 两折距离使用独立闭式坐标计算；三折使用独立 Rodrigues 坐标作参考。断言最终文档的实测距离，避免只断言求解器自己的成功标志。
- 编译操作在空底图上重放，要求有实际改动、无错误，并与预览的图元一致。
- 浏览器使用本地规划器只给底图的夹具，折角由真实求解器计算；这验证产品链路，不是 DeepSeek 理解能力或真实 provider 成功率评测。

可复现的双未知题面：

```text
平面四边形ABCD中，AB=8，AD=5√3，∠BAD=30°，∠ADC=90°，CD=3。
点E在AD上，且AE=2/5 AD；点F在AB上，且AF=1/2 AB。
先将三角形AEF沿EF翻折至三角形PEF，再将三角形PEF沿PF折叠至三角形QPF。
使QB=5.982610851975，QC=7.185772613248。
```

一组通过核验的折角约为60°、70°。删除 `QC` 条件后，两个未知角只有一条终态约束，系统应返回条件不足，而不能把默认90°当成解。
