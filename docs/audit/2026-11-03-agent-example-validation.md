## 结论与评估范围

原题现在能够完整交付“不垂直”的说明、精确长度和推导；常规矩形折叠求长、换点名、换折痕、连续两折等代表题能正常工作。自然语言目标解析和条件完整性仍有明显缺口，尚不能把它当成通用数学解题助手。

| 观测层 | 本轮结果 | 读数含义 |
| --- | --- | --- |
| 独立参考答案对比求解器 | 18 / 24 | 比较数值、真假或条件诊断；没有检查页面是否交付答案 |
| 浏览器交付预期数值／诊断 | 17 / 24 | 用户实际看到了预期结果；不是“17 道完整证明” |
| 明确的能力边界 | 2 / 24 | E06 正方形常用说法未识别；E19 辅助垂足未构造但没有错误否定 |
| 待修复的漏答／条件处理 | 5 / 24 | E10、E13、E15、E18、E23 |
| 提交与一步撤销 | 2 / 2 | 单折 14 个对象、连续两折 21 个对象；均一次撤销回 0，提交后答案保留 |

这组题是围绕用户原题人工设计的变式与边界探针，**不是随机抽样，17/24 不能外推为产品或高考题成功率**。本轮在独立 Microsoft Edge 会话中输入所有 24 道题，使用当前源码的 Web 开发服务和本地规划器；没有配置或调用真实模型服务，没有验证桌面 exe、其他题型或 Lean 形式证明。E05、E22 的“成立”是坐标核验，不按完整演绎证明验收；E07、E21、E24 主要交付近似数值。

## 如何自行复测

最快的体验顺序：E01（原题诊断）、E02（正常求长及作图）、E09（两问）、E14（应当澄清）、E18（应当拦截矛盾）、E23（内部算对但页面漏答）、E24（连续折叠）。下文每个代码块都可以直接复制到 Agent 对话输入框。

1. 启动当前 Web 源码（`npm run dev`），使用未配置模型的独立浏览器配置，进入 Agent 工作区。
2. 每道题新建对话，粘贴完整题面。不要把“存在确认按钮”当成作答成功，核对答案、问题数量、状态和条件冲突提示。
3. 对可作图题确认提交，再回画布检查；E02 应为 14 个对象，E24 应为 21 个对象。一次撤销应恢复空画布，提交前不要混入其他修改。
4. 修改代码后保留本次结果作为历史证据，另记新读数，不要把失败题删掉。

核心结果可重复运行：

```bash
node scripts/validate-agent-answer-examples.mjs
# 有任一目标未满足时退出码为 1，适合修复后的完整验收：
node scripts/validate-agent-answer-examples.mjs --strict
```

脚本读取 [24 题机器夹具](../../test-fixtures/agent-answer-validation-20261102.json)，结果写入 `output/playwright/agent-answer-validation/core-results.json`。默认模式是诊断报告，退出 0 **不等于全部通过**；`--strict` 在本次版本应报 6 个 REVIEW 并退出 1。它只调用求解器，不替代浏览器检查；E23 正好说明两者的差别。脚本见 [validate-agent-answer-examples.mjs](../../scripts/validate-agent-answer-examples.mjs)。

## 独立数学参考

设矩形两边为 a、b，以展开状态为折角 θ=0。另两个顶点沿折痕的投影间距为 `t=|a²−b²|/√(a²+b²)`，到折痕的距离均为 `h=ab/√(a²+b²)`。折后的对角顶点距离满足：

```text
d² = t² + 2h²(1+cos θ)
   = [(a²−b²)² + 2a²b²(1+cos θ)] / (a²+b²)
θ=90° 时：d² = (a⁴+b⁴)/(a²+b²)
折前：d = √(a²+b²)
```

投影不随折叠改变，故该连线垂直折痕需要 a=b。原题 a=4、b=2，不满足；长度为 `2√85/5≈3.6878177829`。反求 d=3 得 `cos θ=−23/32`，θ≈135.9513743259°。E24 第二折只移动 A，B′ 和 D 不动，因此 B′D 的长度保留第一折结果。夹具中的预期值按这些关系独立计算，没有用被测求解器生成期望答案。
