# 真题评测实施口径（2026-11-05）

- 目标：50 道有公开来源、题号、标准选项与解析的高考数学题；优先几何，配图题调用产品 readProblemImages，禁止人工补图意。
- 题源：GAOKAO-Bench 与 GAOKAO-MM 作者公开仓库；保留上游版本、原始条目、图片及 SHA256。它们是二次整理数据，不冒充教育考试院原始扫描。未核实的联考题不纳入。
- 抽样在运行前固定：30 道配图题与20道文本题；不按模型结果挑题，不把项目原有合成夹具计作真题。
- 路径：真实桌面凭据托管的 provider_run → 产品图像读取器 → 产品 ModelPlanner → AgentRuntime/协调器/编译与核验。每题空白文档、独立会话，不自动确认，不写用户项目。
- 统计：交付率（completed 或有草稿的 awaiting_confirmation）；最终选项准确率（严格比对上游答案，分母为全部题，包括识图失败、超时和无答案）；已作答准确率。图形核验与推理正确性不由选项正确替代。
- 图像材料：上游配图原样保留；题干按上游文本排版，与原图拼接供识图。不是原卷整页截图，不人工增加几何关系。含多张选项图时保持其顺序。
- 限额：全局最多450次真实模型请求（另4次能力探测、8次两题链路预检；不纳入正式成绩），每题最多产品默认8次规划请求，单请求90秒，每题180秒；不额外重跑择优。
- 基线不修产品。模型可见输入不包含标准答案或解析。完整输出、识图原文、失败事件、草稿及耗时保存在本地。
- 限制：这是公开高考客观题便利样本，不代表全部数学能力、联考、主观题证明或实际画布交互成功率；公开题存在训练集污染可能。不同工作区按几何类型选择；评测覆盖核心运行时，不覆盖 UI 点击及 AgentRunner 前置本地特例路由。
