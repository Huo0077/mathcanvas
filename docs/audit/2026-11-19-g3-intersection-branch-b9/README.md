# G3-F9 B9：直线与曲线的多交点不能任意画第一个

日期：2026-11-19。0 次新增 DeepSeek 请求；此项为代码可复现的内核输出错误，**不能反推旧36题中某一题曾触发本分支**（旧实验未保存原参数）。

## 复现与根因

`construct_intersection` 对 `intersectPlanarLineAndConicExact` 的返回固定读 `points[0]`。直线与圆、椭圆或双曲线有两个交点时，即使题目要求“左交点”“右交点”，模型无法指定分支，旧回执仍 `accepted` 并把某一交点物化，产生表面成功但图形语义错误。工具向模型公开任意对象字段，存在更大静默忽略风险。

## 本区块方案与结果

- 模型可见 `construct_intersection` 现发布封闭参数：`lineA` 必填，`lineB`/`conicId` 二选一；多交点可通过 `selection=min_x|max_x|min_y|max_y` 选择最左/最右/最低/最高，并说明坐标并列会拒绝。缺少选择或选择对应坐标并列，返回 `repairable/ambiguous_intersection` 而非画错点；未知选择、两种几何源混合、无效字段均可修复拒绝。
- 负例：圆与水平直线两交点未选/不适用轴选择、混合参数时主候选哈希及图元数不变，失败点未物化。正例：左右、上下分别得到 `(-2,0)/(2,0)/(0,-2)/(0,2)`；切点和双直线唯一交点维持既有路径。
- RED：新增两组测试在改动前因 `additionalProperties:true` 及错误 `accepted` 失败；GREEN：B9 定向2测试通过。完整验证：`npm.cmd run typecheck` 通过；`npm.cmd run test:docs -- --maxWorkers=1` 8文件/22用例通过；真实动作/模型规划/冻结运行器/旧合同定向4文件/200用例通过；`npm.cmd run lint` 0错误、34条既有警告；`git diff --check` 通过。

## 限制与下一关

此选择仅适用于2D 直线-曲线至多两个交点；尚未提供单次同时物化两个交点并分别命名的批次工具，也未按题意自动推断“左/右”，须模型显式调用。新无图36题集仍未经独立合同审查（`runnable=false`），旧合同1通过/26失败/9未测与原生交付未测状态不变。完整真 DS 复测需修复和新题集准入达标并另获预算授权。
