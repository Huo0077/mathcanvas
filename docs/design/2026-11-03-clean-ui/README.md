# MathCanvas 简洁工作台

在浏览器中打开 [交互设计稿](preview.html) 可以切换五个页面。稿件使用示例数据，正式实现位于应用的 React 组件中。

- 左栏只显示画布、Agent、设置。三类画布集中在顶部标签，品牌使用静态文字。
- 功能区使用紧凑的图标与文字布局，分组仍可折叠，常用命令可以直接点击。降低平面和立体网格的对比度。
- Agent 首页提供空间折叠、函数切线和圆线相交三个例题。点击后填入输入框，由用户编辑和发送。
- 设置页将连接、能力详情与高级功能分层展示。真实模型评测仍通过原有的费用提示和确认步骤启动。

[Pines](https://devdojo.com/pines) 的折叠面板和轻量控件可作为设计参考。项目用已有 React 组件和样式令牌实现。
