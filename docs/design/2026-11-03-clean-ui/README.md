# MathCanvas 简洁工作台

[交互设计稿](preview.html) 是本次改版的视觉依据。2026-11-03 的返工将布局落实到正式 React 页面。

| 区域 | 正式实现 |
| --- | --- |
| 顶部 | 56 px 品牌与文件操作栏，52 px 工作区与常用工具栏 |
| 导航 | 64 px 浅色模块栏，只显示画布、Agent 和设置 |
| 工具 | 常用工具直接可用，其余进入「构造」「更多工具」「文件」菜单，支持 Escape 关闭 |
| 画布 | 218 px 对象栏、250 px 属性栏、28 px 状态栏，降低三维网格对比度 |
| 立体视图 | 显示选项折叠到「视图选项」，视角操作放在画布右下角 |
| Agent | 680 px 欢迎区、三个例题卡片、760 px 输入区，点击例题后可编辑再发送 |
| 设置 | 模型服务、偏好设置、高级三个分类，支持保存「减少动态效果」偏好 |
| 工程制图 | 共用顶部与面板样式，图纸上下文按需展开 |

正式画布显示当前文件的真实图形。设计稿中的示例几何、示例对话和示例模型配置用于展示布局。模型配置与画布文件继续使用原有存储和运行路径。

Pines 的轻量控件与折叠交互作为参考，正式实现使用项目已有 React 组件和样式。[Pines](https://devdojo.com/pines)
