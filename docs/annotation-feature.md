# 持久化标注

MathCanvas 的标注是文档对象，不是画布上的临时文字。

## 支持的锚点

- 自由坐标。
- 点本身、直线/线段/射线/折线/连接的起点和终点。
- 圆与圆弧的圆心；圆弧的起点和终点。
- 抛物线的顶点和焦点。
- 椭圆、双曲线的中心、两个焦点和两个顶点。
- 派生交点，以及交点集合中的指定交点。

## 使用方式

选中图元后，在右侧“图元标注”区域输入文字，再点击对应特征的“添加”按钮。标注会随来源图元移动、参数变化和重算结果更新；可以在同一区域删除当前图元的已有标注。

标注会写入 `.mgeo` 文件和浏览器草稿，也会随 SVG/PNG 导出。事务层会校验锚点引用，并阻止删除仍被标注引用的图元。
