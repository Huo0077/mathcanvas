# W5 纯文字作图独立留出卷：登记与发布闸（2026-11-10）

> 状态：待外部审题与授权；不是留出卷成绩或 Release。W0 的 7 份原题和 6 份缺原文联考记录不是新的独立留出卷。

## 冻结前材料

1. 从可核对来源逐字收集纯文字可独立理解的作图题。题图必需却无完整文字条件的排除；记录试卷名、年份、题号、出版来源、原文及使用权限，不凭摘要补题、不恢复识图入口。
2. 未参与本轮调参的审题人核对原文、全部必需义务、题目是否有歧义和支持域；用与生产求解器不同的方法算出坐标、结构、长度、角度、真假目标、误差容限，并留下审签。没有独立复核人时只能标“候选题”，不能自填 reviewerIndependent=true。
3. 在首次运行前冻结题集版本、逐题 UTF-8 原文 SHA-256、总清单 SHA-256、数值 oracle 和复核版本；检查开发集相似题并排除已调参样本。报告器的登记元数据只作机器门禁，不能替代对真实来源与独立性的人工审查。
4. 原始请求、逐题输出、私有题目与配置仅存 Git 忽略目录；公开仓库只上传许可允许的原文或可核对来源引用、哈希、脱敏聚合及代码版本指纹。API Key 不进入日志、报告或提交。

## 一次执行与复跑

- 锁定代码提交、题集指纹与模型配置；每题首次单次运行，禁止失败后重试择优。分开记录确定性离线夹具、真实浏览器 UI、随机 Provider，不混算。
- 统计 attempted/drafted/staged/verified/committed/committedWithKnownError/clarification/unsupported/failed；义务覆盖的分母为全部必需义务，另报拒画率、误拒率与逐题失败原因；文字答案独立统计。
- 至少一次全 UI 真流程和一次独立重跑，分别记录分母及差异。提交后读取落盘文档独立复算，不用生产核验器的“passed”充当 oracle。无证书、过期证书、漏条件或错误残差无可点击确认，直接调宿主桥同样拒绝。

## 付费授权与发布阻断

- 真 Provider 调用前必须由用户批准模型名、题数、单题及总请求上限、费用上限；缺一项或不可估成本就只做离线与浏览器夹具。不自行启用第二模型或视觉调用。
- 发布闸：已提交图的已知题设错误为 0、未核验图可点击提交为 0、四道旧题无退化、公开支持域/覆盖率/全部尝试分母/未完成案例。任一不满足，不打 Release，不能宣称任意题 100%。
- 发布后监测拒画率、错图与重复提交；发现错图或闸被绕过则停用作图提交或回滚解题放量，保留复现题，不关闭 W1 证书闸。
