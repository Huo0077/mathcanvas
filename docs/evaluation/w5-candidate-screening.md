## 进入留出卷之前的关卡

1. 外部审题人对照来源逐字核对，记录其身份/版本/审签并给出原题完整条件；任何图示依赖缺失或原题不清楚都剔除。
2. 与生产求解器不同的方法逐问推导数值和几何关系，固定容差与误拒处理；独立复核**不能由本轮实现者自报**。
3. 交叉查重现有 W0 开发集与调参样本；在第一次运行前把题文、来源、独立 oracle 分别取哈希并冻结清单版本。
4. 用户明确授权真实 Provider 的模型、题数、单题与总请求数、费用上限之前，只能做离线/浏览器工程检查。候选题在所有报告中始终标为 unreviewed/unrun，**不得**靠改标志绕过发布闸。
