## 1. 用户目标与范围

目标是按《普通高中数学课程标准（2017 年版 2025 年日常修订）》和高考题型建立**完整覆盖目录**，让支持的证明命题由 Lean 自动核验；所有未表达、未形式化、未证明、资源耗尽的题目明确说明哪一步缺失，不编造正确性。课程标准原件：[2025 日常修订版 PDF](https://www.scmlzx.net/uploadfile/2025/1110/%EF%BC%883%EF%BC%89%E6%99%AE%E9%80%9A%E9%AB%98%E4%B8%AD%E6%95%B0%E5%AD%A6%E8%AF%BE%E7%A8%8B%E6%A0%87%E5%87%86%E6%97%A5%E5%B8%B8%E4%BF%AE%E8%AE%A2%E7%89%88%EF%BC%882017%E5%B9%B4%E7%89%882025%E5%B9%B4%E4%BF%AE%E8%AE%A2%EF%BC%89.pdf)。2020 版只作历史参照。竞赛与自主招生**另建题集、另报覆盖率**，不混入高中课程/高考分母。

“覆盖所有题型”有三个可审计层次，**不能用目录覆盖冒充自动证明**：① 每个课程条目与经核准的高考题型都有版本化 ID、所属章节与样本；② 每类题都有输入解析、形式命题、成功/反例/歧义用例和可解释的失败；③ 在最终宣称该题型有自动证明能力前，代表题确实得到绑定原题的 Lean 内核验过的产物。全域发布前，每个条目都必须填写三个层次的真值，未覆盖不得改名排除。课程中的建模、数据分析、开放探究题也纳入目录；无单一真假命题的输出如实标 `non_propositional`，不伪造形式证明或把它从覆盖率分母删除。任何有限题集**不能保证未来任意自然语言题 100% 自动证明**，该边界必须在 UI/门禁明说。

盘点按课程章节建立，不靠一张手写十项词表臆断“已经穷尽”：预备知识（集合、逻辑、不等式）、函数/导数、数列、三角、向量、平面/立体/解析几何、计数、概率/统计与数据分析、课程标准选修专题及综合建模；高考跨章综合另标多域标签。每一项的权威文本区间由 H0 逐条核对；标准版本变化时必须迁移 ID 和覆盖分母。

## 2. 当前证据与不能继承的结论

旧 N1–N6 的局部任务曾完成；当前见证搜索窄题型且默认关，约束拖动实验性默认关，真实 provider 只有小样本（planning 3/21、工具环 8×3，成本未测），`proof/lean4` 只有 `perpendicular` 一种一般命题的单独运行证据。`lean4Adapter.ts` 的模板使用 `hu: u ∈ Dᗮ` 与 `hv: v ∈ D` 等前提；Lean 校验该条件引理**不等于**原高中题已证明，前提从题设推出的桥接仍未核验；模板部分平面点被忽略，IR→Lean 翻译本身未证明。`proofExport` 尚无普通产品读取点，mathlib 的 `rev = "master"` 未固定。**新目标的完成计数从零开始**，旧 N5 的勾选不能平移为全题型完成。

## 3. 数据流与信任边界

`原文+范围 → 多领域 MathClaim IR（题设/目标/自由量/非命题任务） → 独立核验的语义映射 → 声明所依赖的前提 → 可信命题/证明策略 → 受限 Lean 进程 → 内核结论+axioms → 绑定证据+运行事件 → UI`。模型只提出候选结构和证明草稿，不可以自报“已证明”。不能自动建立的前提要列作未消解义务；若仅验证辅助引理，就显示“辅助引理已证，原题仍未证明”。现有 `ClaimEvidenceStatus` 与 solver status 分离保留；新增自动化运行态 `queued/running/unavailable/unsupported/failed/timeout/stale/verified` 与证据态分别存储，禁止把 `running` 当 `formally_proved`。

**形式化契约（拟新增）：** `CurriculumCase { curriculumVersion, unitId, subtypeId, prompt, goldAssumptions, goldGoal, taskKind }`；`FormalizationResult { claimId, sourceSpan, premises, target, unresolved, translationVersion }`；`ProofJob { runId, claimId, documentFingerprint, inputHash, strategyId, toolchainRevision, deadlineMs }`；`ProofOutcome { runStatus, claimEvidence, artifact?, unresolvedPremises, diagnostics }`。字段必须可序列化穿过桌面桥和持久事件；未消解前提非空时禁止给**原题** `formally_proved`。完整来源、目标、前提、版本和 Lean 命题参与绑定哈希；任一变化产生 `stale`，历史产物只能留作历史，不能再证明新图/新题。

## 4. 自动触发与平台

首批**桌面端**：Agent 产生稳定且可预览的草稿后，后台调度每个可形式化目标；无需每题手动点击，但仍须用户单独确认**草稿提交**，自动证明绝不自动提交图。单次运行/同一 claim 有上限与去重，停止、重试、编辑、会话切换、文档 revision 变化使旧 job 失效；证明计算不阻塞作图或确认，回来时重新比对 run/claim/document/hash，迟到结果拒绝显示为当前证明。浏览器端无本机 Lean 桥时显示 `unavailable`，不偷偷发网络请求。自动证明开关默认关直到安全和用户体验门禁通过；开启一次后符合条件的目标**自动**运行，不再要求逐题点击。无工具链时可继续作图，但如实报告未运行；发布版要审查可复现安装/分发方案，不能把开发机上的 Lean 当用户已拥有。

Lean 运行由桌面受限进程桥实现：固定仓库/发行物中**锁定版本**的 Lean+mathlib；不通过 shell 拼命令、不接受任意路径或模型生成的可执行片段、限制输入长度/内存/时间/并发并清理临时文件。先只运行仓内受信策略模板；任何未来允许模型自由策略文本的版本必须先单独完成隔离评估，不能将测试用 `lean4Runner.ts` 的 Node `spawn` 原样搬进 WebView。Lean 的 `exit=0` 不是通过凭据；保留现有 axioms 白名单、拒绝 `sorry`/不受信公理及失败产物。数学表达与证明脚本分别记录版本，proof artifact 可独立重放。

## 5. 跨题型证明策略

以每个课程子类型为插件单元：声明适用 IR、前提消解、Lean theorem shape、可信策略、反例/未支持出口、金标准用例。先完成“原题题设可导出 Lean 前提”的闭环，再逐域扩张：代数/函数/不等式，数列与归纳，三角/向量，平面/立体/解析几何，导数与应用，计数/概率/统计，选修和跨域综合。策略复用 mathlib 的代数、几何、分析等模块，但“模块存在”不代表本产品支持该题型；每域正例、已知反例、歧义、退化、自由参数与 Lean 失败例必须同时入库。当前垂直性引理只是第一枚种子，不能被当作整个立体几何域通过。

## 6. 发布门禁与先后关系

- **H0 清册**：2025 标准/高考目录逐条映射，题型 ID 无遗漏；类型 `proposition` 与 `non_propositional` 有独立统计，竞赛题独立。原始来源可追踪。
- **H1 状态与翻译**：所有证明产物的前提、目标及版本完整绑定；无源条件不能变成 Lean 假设；有未消解义务时原题证据不升级；故意篡改/删条件/用 `sorry` 的负例必红。
- **H2 桌面自动桥**：固定 toolchain 与许可证/体量/平台审查；缺依赖、超时、取消、资源用尽、并发、关旗旧路径、停止后晚到均有可执行正反例和独立真实工具链烟测。普通 Web 无工具链明确不可用。
- **H3 各域扩张**：每个 2025 标准子类型和高考标签都有已审核金标准与错例；只有测试证明了翻译+Lean+UI 全链路才可标支持。最终“所有题型”门槛是**分母完整、每类能被诚实处理且声明可自动证明的每类确有跨题材代表题通过**；证明型未支持类仍在表内显示缺口，禁止宣称全覆盖。
- **H4 质量与发布**：N2/N3 审查残留、21 条题集真实 provider 覆盖与成本价目表、教师/学生走查、MSI 管理员验收分开报告；真实 provider 付费调用必须先由人确认费用与次数。本地/CI 全套和真实桌面验收分别记数，不以离线评测代替。

优先顺序 H0→H1→H2→逐域 H3；N2/N3 修复与 provider 评测可以并行，但发布要合并审计。每个功能区块：RED（代码断言与正确失败原因）→ 最小 GREEN → 定向/全局门禁 → 当前状态、任务进度与归档同步 → 单独提交 → `origin/main` SHA 核对。旧 N1–N6 文档保留为历史，任何差异在新执行进度中显式裁决。

## 7. 尚待设计复核的决策（不是已实现项）

1. 自动触发点暂定**草稿可预览后**，不是规划文本刚到、也不是确认提交后；需验证目标与草稿 fingerprint 的一致性。
2. 运行环境是用户自备 Lean、发行包带固定缓存、还是受管安装？H2 前必须给出许可、体量、更新和离线策略实测；未决时不能开启默认开关。
3. 开放建模、统计分析等非命题任务的“覆盖”验收由教师审核金标准和可核查的子主张组成，不得计作 Lean 已证明整份答案。
