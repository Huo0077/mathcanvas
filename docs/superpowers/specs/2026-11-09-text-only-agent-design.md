# Agent 文字题专用设计

## 决策
用户明确选择移除题目图片识别，集中于文字题；保留文字描述作图与历史图题记录。此处“移除”指所有可供用户或生产 Agent 发起的新图片读题入口：Agent 对话只接收文字；画布、图元、文字作图和历史消息显示不变。

## 边界
- AgentWorkspace 改为直接使用已有 AgentComposer；Ribbon 的图片识题按钮移除，文字解题按钮进入 Agent 工作区。
- AgentRunner 不再识别或执行历史结构化图片信封，也不领取图像会话；若用户尝试重新运行旧图片消息，需在调用规划器前告知“请把题目和图示条件转写为文字”，禁止把旧图证据伪装成可靠文字。历史消息继续用原有只读解析器显示题图备注，历史数据不删除。
- 生产 UI 中的图像上传组件和真实视觉 provider 调用模块移出运行路径；离线图像证据工具可作为既有历史报告/测试的纯函数保留，不代表产品可用功能。
- 文字作图、已有场景的几何数据、模型配置和其它非题目图片（例如画布导出）不受影响。评测改为纯文字题：旧 20 题只能算开发回归；上线前需独立留出卷与推导审查。

## 验收
- UI 无上传/识别图片入口；Ribbon 只留“文字解题”；文字题和文字作图在 AgentRunner 继续可用。
- 重放旧图题文本不得触发视觉模型、规划器或自动写图，提示转录为文字；旧消息内容仍可查看。
- 全项目类型检查、定向/全量测试、浏览器端文字作图及对话回归通过；不发起新的付费 OCR 调用。
