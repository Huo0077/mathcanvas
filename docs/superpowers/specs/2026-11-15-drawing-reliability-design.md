## 1. 目标与不能偷换的边界

用户目标是尽力把画图能力做到 100%。本设计把它变成可验证的工程目标，而不是承诺任意自然语言题永不失败：

1. **封闭回归目标**：冻结的 36 道原题，在逐题审核的画图合同下，题意、对象、几何关系、实际显示和确认保存全链路 36/36 通过。任何不适用项须在修复前审核、公开原因并单列，不能事后从分母删除；只画公共底图不得称整题完成。
2. **泛化目标**：新题、换数、改名、改写、折叠分支和边界情况持续扩容；独立盲测按题族、样本量、重复次数报告正确率与不确定性。开发集 100% 不等于未见题 100%。
3. **安全目标**：条件矛盾、题文缺失、无法解析、数值不稳定、能力不支持时明确说明，绝不把错误草稿包装成正确图。澄清与拒绝单独计分，不当作出图成功。
4. **范围目标**：优先平面解析几何/圆锥曲线、函数与导数、立体几何、折叠变换；可构造一张满足题设的图不等于证明全称结论，不在本轮扩张成自动解答/自动证明全课程。

“欠定”不必一律拒绝：存在自由参数但可构造合法示意图时，可以选择明确标记的自由值；禁止把选值当成题设或唯一答案。真题中需要穷举的解支、动点范围与不等式域，不能被一张数值实例替代。

## 4. 路线比较与选择

| 路线 | 好处 | 主要风险 | 决策 |
| --- | --- | --- | --- |
| 仅换更强模型、提示词与更多重试 | 改动小、适合语义理解 | 坐标和拓扑不可靠，成本增加，覆盖仍不透明 | 只作对照实验，不是主路线 |
| 所有题硬编码模板 | 已知题型稳定、结果易测 | 题号过拟合、组合约束覆盖不足 | 模板只作为可组合的确定性构造器 |
| 模型理解 + 确定性构造 + 独立验收 | 可解释、可回放、复用内核，错误可定位 | 前期合同与校验工程量较大 | **推荐主路线** |

不从零重写平台。保留已有 ObligationIR、原文解析、几何内核、solver、deterministic-first 路由、草稿隔离与确认提交；补齐合同和能力缺口。暂不直接引入大型 CAS/SMT 或新 provider；只有内部能力无法满足明确合同，才做隔离验证并单独决策依赖、许可和维护成本。

## 5. 目标架构：一条可追溯的生产链

~~~text
原文/经核对题图 → 原文锚点与表达式 AST → ProblemContract（扩展现有 ObligationIR）
  → 作用域/实体/参数/分支分析 → 构造意图 DAG
  → 确定性构造与有界求解 → 隔离候选场景
  → 独立数学/覆盖/拓扑校验 → 实际渲染与交互检查
  → 绑定最终候选的验收证据 → 用户确认 → 原子提交/撤销/保存重载
                 ↑结构化诊断 + 共享预算的局部修复↓
~~~

每个节点记录输入 hash、版本、输出摘要、失败类别和耗时。生产与评测调用同一入口；评测不得绕过校验器，不得凭模型一句“已满足”生成证书。评测适配层只替换传输、时钟和隔离存储，不替换决策逻辑。

### 5.1 题意合同：扩展已有 IR，不平行制造第二真值

现有入口：packages/agent-core/src/obligationIR.ts、diagramObligations.ts、promptNormalization.ts。拟增加的 ProblemContract 是 IR 的封装/演进层，旧接口通过显式适配迁移。

合同至少包含：

- immutableSource：原题文本、题图及核对版本的 hash；每条条件有 sourceSpan/图像区域、提取方式与状态。
- entities：稳定 ID、类型、显示名、别名（A1/A₁）、所属曲线/实体、折叠前后 state ID；别名不跨状态随意合并。
- scopes：公共题设、小问专用条件、假设分支、选择项、待证明目标。公共对象可复用，冲突小问单独图状态。
- obligations：表达式 AST、关系、参数域、单位、目标实体、来源、适用 scope、支持级别。模型提出的关系只作提案，不能覆盖原文。
- constructionIntent：必需对象、依赖和辅助对象；区分“给定”“推导得到”“自由选值”“仅展示”。
- coverageLedger：每段原文是否映射、每项义务是否可核验、理由；无法识别的条件必须显式 unknown，不得丢弃后宣称完整。
- decisions：多问选择、歧义澄清、欠定自由值、分支选择及其依据；不能静默缩小任务范围。

规范化保留原文与 AST 双向映射；只能做可证明等价的格式变换，推导结论另存并校验。planCompiler 中 plan.normalisations → applyNormalisation 的链路重点追踪；已有改写守卫应加强，不盲目移除或无条件相信模型文本。图像只贡献有来源、可核对的事实；低置信 OCR 不可直接作为确定题设。

### 5.2 解析：从补正则升级到可组合语法

统一 Unicode/LaTeX/上下标/负号/隐式乘法/分式/幂式表示，建立等价 AST 测试。链式关系拆成有共同来源的原子约束，不截掉右侧；选择项不默认加入题设；动点域、参数域和小问条件保持 scope。多曲线使用实体引用，不再要求“全场景唯一曲线”。原文明确给出标准式即可从语法语义推得其中心/坐标系，不依赖模型补一句“中心在原点”。

解析失败应区分：语法不支持、实体未绑定、条件有歧义、题文确实缺失、内部错误。必须附 sourceSpan 与建议，不能把引擎不会读描述成用户没给。

### 5.3 确定性构造与求解

**平面/解析几何**：复用 geometry-kernel 中 expression、numeric、conics、conic-parameters、conic-line、curve-intersections；先构造曲线实体，再解析点、焦点、交点、切线、弦和轨迹依赖。多解枚举后以原题域过滤；无根/切重根/竖直线/极值附近有专门测试。函数与导数显示完整要求的函数及辅助对象；有限窗口采样不能当作全域性质证明。

**立体/折叠**：复用 solver/prism、pyramid、tetrahedron、foldHinges、coupledFolds、witnessSearch 等。先参数化局部坐标/长度角度，再求约束和拓扑；严禁模型直接猜一组顶点就当通用多面体。检验面共面、面环简单、相邻面方向、连通、闭合/开放面语义和非退化体积。合法开放折纸面不能被强制当闭合多面体。辅助点要有明确宿主和参数，不能只出现在模型文字里。

折叠采用变换谱系：原面/铰链/角度/转向/前后点对应/当前状态。保距与目标折角分别核验；两折顺序及分支明确，不将折前 D、折后 P 直接别名合并。

求解报告区分 satisfied、proven_unsat、underdetermined、not_supported、budget_exhausted、unknown。数值搜索没找到点不能叫“无解”。必须显式给出尺度相关容差、奇异性/病态诊断和残差；可行时用解析/精确值，数值路径不靠粗放宽容差过关。

### 5.4 有界修复：一次预算，按故障修局部

复用 coordinator、modelPlanner 的既有修复与传输机制；网络重试、schema 修复、构造求解和模型重规划共用可观测预算，不再叠一层无限循环。

- 结构化诊断包含 obligationId/entityId/sourceSpan、expected/actual/residual、失败阶段、是否可自动修复。
- 格式/别名/依赖顺序优先本地修复；几何不可行先更换合法参数或分支；语义歧义才澄清。
- 只重算受影响 DAG 子图；保留正确上游，修完仍重验完整合同。
- 候选 hash + 失败签名重复则停止；达到预算明确失败原因与未满足项。
- 取消、网络错误和用户修改使异步候选失效；不允许迟到结果写入场景。
- 新阈值必须由离线回放后校准，记录首轮与有限修复后两种成绩；未经用户同意不扩大付费请求。

### 5.5 独立验收：不让“自己说自己对”成为标准

复用 diagramVerification、verification/taskAcceptance 等基础，新增完整覆盖账本与候选绑定层（新文件名由实施时在计划给定范围内确定）。覆盖账本从审核后的源合同出发；校验器读取最终图元和依赖，不仅读取构造器的计划声明。

验收至少包含：

1. 来源与 scope 完整；必要条件没有未绑定/不支持项。
2. 必需实体和辅助点存在、类型正确、状态正确、没有重名错绑。
3. 几何条件逐条独立计算，域/分支/非退化/拓扑合法；数学失败与仅解析缺口分开。
4. 最终实际显示包含应显示对象，点名、连线、虚实线、相机与范围可读。
5. 隔离草稿到确认、撤销、重做、保存重载的一致性。

拟定证据包含 sourceHash、contractHash、candidateHash、scope、validatorVersion、renderEnvironment、逐条判定、coverage、容差、未检查项。只有所需项全通过且无未支持义务才能“完整通过”；partial/unknown 不升级。候选、参数、题文、分支、版本、相机或渲染设置改变时，相关证据失效。实例证据只证明该图满足所列条件，不声称整题全称命题已证。

“独立”需要反例证明：错误坐标/删点/交换实体/改折角/漏条件/篡改 AST/过期候选都应拒绝。核验与构造共享基础算术可接受，但不能用同一个高层推导结果互相背书；关键题另有手工审核的解析参考或第二算法回代。

### 5.6 最后一公里：实际画布与交互

数学正确不等于好图。覆盖平面/立体/折叠/函数四族：自动合适视窗、相机角度、字体/点名避让、隐藏线、对象不越界、不让关键点完全遮挡。截图/视觉检查不替代数学断言，也不能用主观“看着像”放行。

验收同时读取真实渲染后的对象/标签/投影或拾取数据，配合固定视口截图人工走查；提交前主文档零写入、一次确认只提交一次、一键撤销、保存重载等真实桌面链路必须测试。拖动绑定对象须保持约束；自由编辑破坏条件时撤销旧证书并明确提示，不能保留绿色通过标记。

## 6. 统计与评测合同

所有百分比都带分子/分母、合同版本、题族、scope、模型/路由、单次或多次、首轮/修复后、核验覆盖范围。不能把 8/36 partial exact 当作真实正确率。

| --- | --- | --- |
| 出图率 | 有非空候选 / 冻结输入总数 | 空图、澄清、仅有文本 |
| 题设覆盖 | 已被表达且有核验能力的必要义务 / 审核必要义务 | 丢条件、unknown、只统计已识别条件 |
| 数学正确率 | 完整覆盖且所有数学义务通过的题数 / 冻结总数 | 只验证几条、只画第一问、自由值伪装推导 |
| 视觉通过率 | 实际渲染达到审核规范的题数 / 冻结总数 | 标签缺失、遮挡、视窗外；可另报条件于数学通过后的读数 |
| 端到端通过率 | 数学 + 视觉 + 草稿确认/保存链路全通过 / 冻结总数 | 只有核心回放或宿主 passed |
| 安全处理率 | 正确澄清/拒绝的负例 / 审核负例数 | 有解题因解析器缺陷被误说缺条件 |
| 修复效率 | 首轮通过、有限修复后通过、请求/token/耗时分布 | 只报最好一次 pass@k、隐去失败和成本 |

**数据分层**：冻结原题集（36，开发回归）；参数与语法变式集（按能力派生、不能泄露盲测）；独立未见题集（出题/审核与修复调试分离）；负例与变异集；带配图/OCR 集（与题文模式分开）。固定原题文字、hash、预期合同和版本；题意纠错通过单独记录审议，前后成绩都保留。

**建议发布门槛，待批准后冻结**：36/36 完整端到端通过；每条必要义务均有正例和可识别反例；至少 120 道独立审核未见题、每族至少 30 道，冻结首轮与修复预算后做 3 次运行，逐轮报告（不能只取最优）。首轮端到端目标 ≥95%，有界修复后目标 ≥99%，每族不得被总体掩盖；错误图误标“完整通过”在审核负例中为零，安全处理另报。若样本量不能支持精细百分比，报告原始计数与置信区间，不把一次零失败描述成可靠性 100%。这些是未来门槛，不是当前成绩或付费授权。

P0 应审议抽样方案与置信区间计算方法；公开运行次数与样本相关性。盲测失败一旦进入修复就进入开发集，下一轮另留新的盲测题，禁止调到过后仍称“未见”。长尾不能通过删除失败样本处理。

## 7. 分阶段策略与验收总览

所有阶段的运行状态均由[当前状态](../../current-status.md)维护，下表只是固定退出合同。

| 阶段 | 交付能力 | 必须达到的退出条件 |
| --- | --- | --- |

| P1 来源与语义合同 | 扩展现有 IR、scope、实体 ID、来源分离 | 所有必要义务可追溯；模型推导不能覆盖题设；不确定项显式阻断完整通过 |

| P3 平面确定性构造 | 曲线、焦点、交点、切线、函数与轨迹 | 18 道平面题在批准合同下数学/对象覆盖 18/18；不支持项不隐藏 |
| P4 立体与折叠构造 | 参数、拓扑、变换谱系、辅助点 | 18 道立体题数学/对象覆盖 18/18；正反折/退化/无解与开放面反例齐全 |

P6 的安全接口与负例设计从 P1 同步定义，不能等构造做完才想验收；P6 的最终关卡在 P3/P4/P5 集成后。P3/P4 依赖同一合同，先以接口稳定为前提分别实施；不等于本轮授权并行调用代理。

## 8. 发布、回滚与不做事项

新路径分阶段接入现有 deterministic-first 入口，默认保留旧路径供对照与回滚；关闭新路径后不得仍显示新证书。每阶段小范围改动、红绿测试、人工审查、独立证据和可回退提交；先离线，再受控真实请求，最后真实桌面和灰度。完整回归必须防止已有手工作图、拖动、存档和确认安全被破坏。

不做：单凭换模型宣称完成；扩大超时/轮次掩盖根因；放宽容差删断言；向模型泄露黄金答案；以回放/截图代替真实 provider/数学验收；引入自动 Lean 整题证明承诺；一次性重写全仓；本轮付费重测或发布。

## 9. 待用户批准的决策

下一步优先批准审查驱动方案的R00/R01-A/R09-A/R10首批安全与计分闭环，随后G1/G2及原P0/P1继续推进。C1止损不等待36题黄金合同全部完成；文档修订不等于批准执行或发布。

- 接受“模型理解 + 确定性构造 + 独立验收”主路线；优先修合同/解析而非先换模型。
- 审核 36 题的公共图/分问/辅助对象范围与自由参数策略，保持整题分母透明。
- 冻结支持范围、P8 样本与发布门槛；真实模型复测前另定请求/token/费用上限与停止条件。
- 接受长尾题诚实降级，不把澄清/拒绝算作画图成功；最终以端到端证据而非进度百分比签收。
