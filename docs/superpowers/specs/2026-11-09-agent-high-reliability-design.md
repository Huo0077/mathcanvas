# Agent 高可靠解题升级设计

**日期：** 2026-11-09。
**状态：** W0—W3 的实际进度以当前状态页为准；W4—W11 暂停。百分比是研发目标，不是已有结果或成功保证。
**基线：** 4.4.0 / 8aa2d34d2146dd2d5f9605947d21ccbfdac18857。

## 1. 决策摘要

采用“一个生产协调器 + 可追溯题意 + 专项求解/核验 + 有限恢复 + 按风险升级模型”。核心目标是把完整、正确、可交付的解题成功率推向98%—99%以上，同时约束错误认证率、覆盖率、延迟和成本。对任意未知题保证100%没有证据基础，不作为承诺。对外声明必须绑定题目范围、版本、模型、预算、样本量与置信区间。

这不是重新创建11月8日已经交付的模块。此次主要工作是生产接线、扩展实际支持域、恢复闭环、独立核验和真实入口评测。只有模块单测通过不算完成。

| 路径 | 好处 | 局限 | 决策 |
|---|---|---|---|
| 只换模型、改提示词 | 改动少 | 不修schema、证据、识图丢失和验收缺口；没有本项目对照数据 | 作为受控对照 |
| 多模型投票 | 可以发现分歧 | 共同误读会一致答错；多数票不是证明 | 仅用于困难题候选，不认证 |
| 保留runtime，补可信输入、独立核验和受控恢复 | 可定位、可回滚、可测量 | 需要宿主接线和题族适配 | **采用** |

## 3. 目标口径：完整解题率与错误认证率同时约束

### 3.1 指标

对预先冻结题集N同时报告：

- **交付率D/N**：全部必答小问均有类型正确的终答；要求作图时有合法待确认草稿或确认结果。只有思路不算。
- **旧严格选项率O/N**：保留历史可比性，不作为唯一主目标；新评分器必须版本化并同时重评旧、新结果。
- **完整解题率S/N（主目标）**：成功交付，且所有必答结果、必要关键推导、要求的图形经过独立参考或人工复核正确。未审结不算成功，单列数量。
- **已交付正确率S/D**：辅助指标，D=0为null，不代替S/N。
- **可信认证覆盖率V/N**：宿主适用域内有有效、覆盖全部必答目标的核验证据；模型互相赞同不计认证。
- **错误认证率F/N及F/V**：错误但标已核验。V=0时后者null，不报告0%。
- 一次通过率、恢复成功率、逐问完成率、请求/token/延迟、失败原因分布。

澄清、超时、能力不支持、provider失败都在N里。普通可解真题被澄清仍为未完成。确实缺材料的异常题可另报“安全处理正确”，不与正常题成功数混加。用户补充后成功另报“有人协助成功率”，不能覆盖自主首轮。

### 3.2 阶段门槛（目标，不是预测）

| 阶段 | 工程门槛 | 解题门槛 |
|---|---|---|
| G0 测量可信 | 互斥分母、结构化选项、来源/构建/运行版本齐全；补推导审阅基线 | 不以涨分验收 |
| G1 生产闭环 | 真入口调用题意、核验、重读；错误可阻断，协议故障可恢复 | 固定50题三轮旧口径每轮≥43/50；交付每轮≥48/50 |
| G2 能力扩展 | 所选题族有独立核验；图从可信数学模型生成 | 冻结100题验证集S/N≥95%；图题≥90%；错误认证0 |
| G3 候选发布 | 完整UI、故障注入、预算、构建证据齐全 | 正式冻结500题S≥498，D≥499；各题族≥95%；错误认证0 |
| G4 稳定运行 | 同配置再跑两轮，不择优 | 两轮S/N各≥99%；0错误认证；重复题不当作新独立样本 |

Wilson双侧95%区间：498/500约98.55%—99.89%；即使50/50，下界仅约92.86%。这些计算依赖抽样假设，不是未来任意题保证；按试卷/模板分组另报相关性稳健统计。不能因为固定50题全对就宣布通用100%。

范围、题族、难度、含图比例、工具和预算在盲测前冻结。范围外请求仍计入“全请求成功率”，另列未知题型。可以另报支持范围认证率，但不能替换全量指标。若某题族没做完，门槛就是未达成，不能临时删题。

## 4. 目标生产架构

~~~mermaid
flowchart TD
  A["原题、附件、场景快照"] --> B["同一解题会话：身份、预算、取消"]
  B --> C["图像定位、转录、证据审计"]
  C --> D["题意：条件、子问、状态、来源"]
  D --> E["支持域与策略路由"]
  E --> F["确定性题族或模型候选"]
  F --> G["结构、工具协议、独立数学核验"]
  G --> H{"交付条件满足？"}
  H -->|"是"| I["逐问答案、证据等级、草稿确认"]
  H -->|"可恢复"| J["定向重读、格式修复、独立候选"]
  J --> C
  J --> F
  H -->|"预算耗尽或缺条件"| K["部分结果、原因、针对性澄清"]
~~~

这是现有协调器的有界阶段，不另建任意循环的总Agent。恢复只回到对应故障步骤，不反复重解整题。

### 4.1 身份、题意与信任

- 原题UTF-16区间、附件hash/区域、题目修订、场景修订分别保存；不同题不能共用空场景hash作为题目身份。
- 题目修订由原文、附件内容hash、用户修正生成。原文区间不能用规范化文本下标冒充。
- 题设、辅助构造、自由坐标、推导、选项分区；选项不反向补题设。
- 每问有类型、定义域、单位、折前/折后状态与显式依赖。未识别数学目标不能偷偷改为conversation并算完整。
- 关键条件有来源不等于识别正确；模型自报置信度不能升级信任。
- 条件消费允许有证明的冗余，不要求机械使用所有文字；模型不能自称“冗余”就绕过约束。

### 4.2 图像闭环

保留原图、题干/图形/选项区域、裁图到原图坐标变换。分别提取尺寸、虚实线、点线关系、网格、视图身份、图形选项。只有“图1”定位不能支持体积计算。

审计缺什么关键数据→最多2次定向局部重读→合并/保留冲突→重新解析目标依赖。相同区域、参数和模型无新信息不重复请求。关键读图冲突不能仅由多数票裁决；来源hash只证明追溯，不证明像素解释正确。

图形选项用定义域、零点、符号、极值和对称性匹配，不让模型猜“最接近”。多种可行图形若目标值不同，澄清；如果全部合法候选目标一致，可在声明条件下交付共同值，不能挑最合选项的图形。

### 4.3 求解器与适用域

| 批次 | 题族 | 独立核验 | 边界 |
|---|---|---|---|
| 首批 | 圆锥曲线/垂足/偏心率 | 原曲线代回、垂直、顶点/端点、开闭区间 | 现有有限判据外unknown |
| 首批 | 立体/折叠 | 刚体不变量、点线面、距离角度、状态对应 | 缺角度不默认90度 |
| 首批 | 三视图 | 共享轴、尺寸、候选实体、反投影、解析/网格 | 不把两类实体当通用重建 |
| 第二批 | 函数/三角/绝对值 | 定义域、分段符号、零点极值、图形选项 | 抽样不证明全域 |
| 第二批 | 数列/连分数 | 精确有理数、奇偶子列、递推与归纳 | 有限样本不能证明所有n |
| 第二批 | 平面/概率统计/混合 | 几何约束、有限计数、分布条件、组合量 | 没有独立适配器不得标已核验 |

先复用现有内核、表达式AST和判据，补有限有理数/多项式规则。禁止eval、模型任意脚本及任意网络/文件操作。通用CAS、形式证明后端需要单独依赖评审，不作为首批修复前提。

### 4.4 核验的真实性

核验相对于确认过的原题，不是只检查模型内部自洽。证据绑定题目修订、目标、候选hash、来源修订、核验器版本；改答案/题设立即失效。

解析和网格体积一致只验证同一模型的内部计算，仍需反投影证明模型对应图像。找到反例必须阻止候选；没找到反例最多sampled/unknown。形式证明须有可独立检查产物。

EvidenceRecord增加可选绑定字段兼容旧会话；新流只认证完整绑定的宿主记录。旧正文继续显示为历史未重新核验，不因为读到旧answered就升级。证明题未覆盖全链时不得标完全核验；完整解题率需人工或独立证明检查。

### 4.5 工具与恢复

schema、允许动作和示例从运行时注册表生成。先分answer/clarification/plan；纯解题不是空actions的plan。工具结果ID由宿主返回，模型只能引用当前真实结果，不拼scene:doc。

| 原因 | 可恢复动作 | 禁止 |
|---|---|---|
| schema错误 | 1次字段路径+允许键+合法示例的定向修复 | 无限“再试一次”、执行非法动作 |
| 缺图条件 | 最多2次局部重读，仍缺再澄清 | 编尺寸、靠选项补条件 |
| 无效工具引用 | 1次真实引用表修复，重新验受影响结论 | 关闭门禁、删引用后继续标已核验 |
| 数学反例 | 1次定向修正，必要时换策略 | 直接换答案字母 |
| 解法冲突 | 先核题意，再独立候选和核验 | 投票认证 |
| 网络瞬断/429 | 现有分类退避并共享计费预算 | 对鉴权失败盲重试、换账号 |
| 不支持 | 已批准适配器/模型升级，否则未完成 | 假称已支持 |

局部额度都受全会话总预算限制，不是每类重新领取预算。

### 4.6 模型路由

不预设某品牌最强。使用已经保存且获授权的primary、vision、independentSolver角色配置，没有配置就关闭该升级路径。视觉不足升级视觉，数学否证才升级求解。

一次尝试冻结profile/revision；升级建立新attempt，记录理由，不能静默换配置。独立候选首次只看原题与可信事实，不看前一个选项；这减少锚定，但不保证统计独立。最多两个候选，冲突用核验裁决，不新增一个裁判模型作为唯一正确性来源。

模型选择使用同验证集和预算，比较准确率、时延、成本、失败分布；盲测不用于选模型。

### 4.7 交付与作图

逐问展示答案、状态、证据、未完成原因。普通聊天维持conversation。解释从已选候选和核验数据生成，不得改动结构化值、单位、范围。要求作图时图形约束、显示、依赖更新也要验收；未要求作图时辅助草稿失败不应抹掉独立正确终答。

已核验、实例核验、抽样、未核验、待澄清分开标记。核验开关回滚后保留正文但降级标签。

## 5. 预算、时延与安全

以下是建议配置，需实施评审，不是本次付费授权。

| 限额 | 默认 | 用户主动高精度 |
|---|---:|---:|
| 全会话provider调用，含识图和网络重试 | 8 | 12 |
| 局部重读 | 2 | 2 |
| 独立候选总数 | 1 | 2 |
| 本地工具调用 | 24 | 32 |
| 墙钟总时限 | 180秒 | 300秒 |
| 输出token总上限 | 16000 | 24000 |
| 输入token预留上限 | 96000 | 160000 |

从首次识图起计账，发送不重置。表中墙钟指自动执行段累计时限；人工核对由宿主明确暂停计时，请求/token不重置；会话绝对存活最多30分钟，超时提示重新发起，不静默续费。调用前预留，usage后结算；无usage保留保守预留，不按0计。token估计不等于账单；没有已确认价格表不承诺金额上限。拒绝超限发生在下一次请求前；取消不能保证在途不收费。

缓存键含原图hash、裁图、profileRevision、提示和解析版本，不能跨题误用；独立评测轮禁止把缓存当新成功。批次另有总限额和kill switch，不能每题重置。

原生密钥不导出；图片中的指令视为数据；核验禁止任意执行；切会话、取消、场景变化、重启必须防旧结果回写。失败不写真实文档，确认仅提交对应版本草稿。

## 6. 数据、测试与验收

### 数据集

- 开发300题：已有50 + 新250，可查看错误/变式；暴露过不再叫盲测。
- 验证100题：选模型与阈值，不作为最终泛化成绩。
- 正式盲测500题：开发期间不查看运行结果；按试卷/模板/图像相似去重。
- 异常100题：缺图、遮挡、矛盾、注入、预算、取消、错引用，独立报告安全处理。

正式500配比建议：三视图80、立体/折叠80、圆锥曲线70、函数/三角70、数列60、概率统计50、平面50、跨题型40。含图至少50%；覆盖适用的选择、填空、解答证明和作图。这是采样方案，不表示数据已准备。

来源优先可核对的高考原卷、教育考试机构公开材料和有授权的联考卷。保存卷名题号、来源、原图、参考、关键步骤、许可与hash。“如图”缺图不能改成纯文本送测。材料缺陷冻结前修复；冻结后记录并执行预先约定的无效题政策，不能临时删除失败题。

### 防泄漏与独立审阅

标准答案只在评分侧，不能进入模型上下文或工具可读目录。相似题/改数字题不跨开发与盲测。公开高考原题可能出现在模型预训练中，本项目的盲测只保证对本次开发隔离，不能证明模型从未见过；另加带独立真值的改数、改图和条件反事实测试验证泛化，并单列结果。盲测失败曝光后转回归，下一发布用轮换保留集。

所有计入完整成功的题核对参考结果及关键推理；证明、几何多解和疑似题源错由两人独立审阅并仲裁。只抽审100题，不能宣传500题推导全对。标注与API预算单独估算。

### 三条跑道

1. 本地确定性/回放：失败机制、故障注入，不花API费，不冒充真实模型。
2. 共用生产服务的实时评测：同识图、路由、协调器、核验、预算与结果，不绕过特定路由。
3. 桌面完整UI：真实上传、识图、发送、显示、预览/确认、撤销/取消/重载；至少40题分层付费抽测。只有40题走UI时不能称500题UI端到端。

每批记录Git、binary与前端buildId、模型配置、schema/核验器版本、数据hash、题号、所有尝试和用量。先构建并启新实例，核验页面与原生程序指纹，不只看HEAD。

## 7. 资源、里程碑与回滚

12个工作包粗估41—65工程人日，另计题库授权、人工标注/审阅和真实模型运行；单人约8—13工作周。两人可在依赖允许时并行，但不承诺具体日期。广覆盖证明/概率能力超出估计时追加建设，不能删题兑现排期。

阶段A W0—W3：统计、身份、预算、生产接线。阶段B W4—W7：识图、工具恢复、数学、三视图。阶段C W8—W11：模型路由、呈现、生产评测、灰度。各工作包产物和命令在实施计划。

使用现有5个开关，新增配置依赖检查。shadow只比较不升级标签，额外模型调用仍计预算；默认先本地shadow。10%→50%→100%按会话稳定分桶，不在一次解题中换档。

立即回滚：错误认证、越权写、跨会话/过期证据、预算绕过。暂停扩量：交付下降超过2个百分点、P95超预算、题族退步超过5个百分点。回滚关闭新策略并降级标签，不关闭旧门禁。
