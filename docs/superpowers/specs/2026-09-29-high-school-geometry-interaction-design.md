## 1. 目标与参考的准确边界

参考视频：[MathMover 2.0 发布演示](https://www.bilibili.com/video/BV1iDQyBmEUj/)（用户提供的短链：https://b23.tv/ahgHOOH）。已核对 47 秒视频的页面简介及关键画面：约 9–17 秒展示上传题目截图、生成可调参数的平面几何图；约 19–24 秒展示题型卡片，包含立体几何示意图；约 27–32 秒展示导出 HTML / GeoGebra 与独立交互图；约 37–40 秒展示 BYOK 设置。**视频没有完整演示立体图元的手工创建、拾取、拖动或约束语义；不能用它来证明具体 3D 手势可用。**

用户问题：立体绘制反直觉；可用图元不足以覆盖高中常见作图。目标是让教师/学生不懂内部拓扑、DSL 或先选点规则，也能从题意快速构造、修改、标注并导出可复核的数学图。参考视频的启示是“低门槛输入→可检查、可调参数的结果→便捷分享”，但不是直接复制 UI，更不把 AI 识图结果当成已验证的几何事实。

## 2. 项目现状与证据

- 结构：`apps/web` React 工作台、`packages/dsl` 文档契约、`packages/geometry-kernel` 几何、`packages/scene-graph` 事务，3D 用 Three.js；见 `docs/architecture.md`。
- 已有 `point3/line3/segment3/ray3/plane3/circle3/face3/polyhedron3` 等文档类型；有立方体、棱锥、圆柱、圆锥、正四面体和底面+向量构造棱柱的底层能力。不能称“完全没有立体图元”。证据：`packages/dsl/src/types.ts`、`packages/scene-graph/src/actions/index.ts`、`apps/web/src/creationCommands.ts`。
- UI：`apps/web/src/ribbonCommands.ts` 与 `components/GeometryToolbar.tsx` 中，空间直线/平面/面要求先选 2/3/≥3 个点；`point3ToolCommands.ts` 的“加空间点”落到计数格点，而非指针当前点击位置。`threeSceneInteraction.ts` 主要处理选择/旋转/移动/截面拾取，尚无统一的“选工具→直接在 3D 画布上逐步放点/边/面”创建会话。
- 已有自动取景、模板拓扑、圆轨道、截面、交线/交点预览、测量、撤销/重做和工程图；不能为了新流程回退这些能力。参见 `docs/feature-catalog.md` 与现有 `e2e/geometry3d*.spec.ts`。
- 棱柱底层 `compileSolidPrism` 已有，但手工 Ribbon/工具栏目前未见同等入口；球不是现有实体图元（需另立数据、计算、渲染及保存契约）。现有外接球/内切球读数不等于可编辑球体。
- 截图→Agent 路径目前有草稿与人工确认门禁；真实模型/截图场景的稳定通过率及视觉验收不足，见 `docs/acceptance/agent-release-gate.md`。这条路径不作为手绘体验改进的前置条件。

## 3. 核心使用场景和验收样题

| 编号 | 场景 | 完成标准（用户行为） | 优先级 |
| --- | --- | --- | --- |
| S1 | 作点 A、B、C，连 AB / BC，过三点建面 | 用工具后直接在画布按步骤拾取/空白落点；不必先点三次“加点”并 Shift 多选；同一步可撤销 | P0 |
| S2 | 任意三棱锥/四棱锥和三棱柱/斜棱柱 | 选模板→给底面或参数→立刻预览→确认；顶点名字、侧棱和面能继续编辑/测量 | P1 |
| S3 | 长方体、正方体和一般棱锥 | 参数准确（长方体三边可不同），底面与高度可调，拖视角不改几何 | P1 |
| S4 | 隐藏棱、辅助线、截面和角/垂直标记 | 清晰区分可见线与手动教学虚线；旋转视角后自动可见性不与用户指定的教学线型混淆 | P1 |
| S5 | 球、球与平面的圆截面（可选扩展） | 中心/半径可编辑；截面为真实圆，不以多边形视觉近似冒充精确数学结果 | P2，单独评审 |
| S6 | 函数/解析几何的教学附图 | 现有平面工具不回退；专题样题（抛物线焦点准线、切线、弦、参数）可完成，不强制新造低层类型 | P2，先盘点 |
| S7 | 从题目截图生成可编辑图 | 草稿需核对点名、坐标/约束、歧义；用户确认才写入文档；无可信几何时能拒绝 | 独立探索，不阻塞 P0/P1 |

验收集至少覆盖三棱锥高线与截面、斜三棱柱、长方体异长三边、圆锥截面、空间直线与平面的关系、已有文档恢复与撤销。每个样题保存为可重放的测试输入或测试操作序列，不依赖单张“看起来像”的截图。

## 4. 可选路径与推荐

- A（仅补按钮和模板）：快，但继续“自动落点→凑齐多选→执行命令”的心智负担。仅适合短期补缺。
- B（**推荐**：统一 3D 创建会话 + 复用现有构造器 + 分期补教学图元）：先解决“怎么画”，再补“画什么”。当前编辑、撤销与内核契约可复用；需要专门处理相机/拾取和预览优先级。
- C（优先上截图 AI 生成）：可模仿视频的入口，但模型准确率、图意歧义、编辑可控性和发布门禁都未成熟，不应替代手工基础路径。

推荐先做 B 的 P0/P1；A 中低风险入口可合入 B；C 放到单独探索与质量门禁。保留现有“先选对象再执行命令”的高级流程作为兼容途径，不强迫老用户重学。

## 5. 拟议交互契约（待确认）

1. **模式分离**：默认“选择/旋转视角”，点击“点/线段/空间直线/射线/空间面/平面/圆/实体”才进入创建。顶部明确显示“第 1/2/3 步”、可撤销上一步、Enter 完成多点路径、Esc 取消；失焦或切工作区取消未提交预览，绝不留下半成品。
2. **3D 落点没有唯一深度**：空白区域仅在可见工作平面（默认 `z=0`，可切 XY/XZ/YZ/已选平面）求交；指向已有点/边/面的吸附优先于工作平面。悬停标出目标名称、坐标及“在面上/边上/工作平面上”。视线与工作平面近平行时禁用落点并给出提示，**不猜深度**。可用数值输入精确修改 XYZ。
3. **一步式创建**：按“线段”→点 A→点 B；A/B 已存在则引用，空白则创建自由点。所有新增对象一次事务提交，一步撤销；拖动被引用点能带动线/面。直线/射线/面按自身的点数、共线/共面条件校验，错误停留当前步骤而非“按了没反应”。
4. **相机和创建冲突**：创建模式下主键点击/拖动只管理构造预览；中键/已存在的视角控件仍可平移/旋转。选中/模板/截面/交点预览必须具有显式拾取优先级；不得让自动交点预览抢走创建点的点击。
5. **对象语义**：“长方体”与“正方体”视觉/名称/边长参数分开；一般棱柱、棱锥优先复用现有 `polyhedron3` 构造与稳定子图元 ID；除确有无法表达的语义才扩 DSL。模板创建在鼠标放置/属性填写之后才落盘，不再无条件放到远处象限。
6. **教学表达**：能单独控制辅助线虚实与可见性；自动遮挡虚线和教师手动虚线用不同来源/开关；空间点名清晰、标注不盖住关键棱；适配高 DPI、窄屏、键盘与 reduced-motion。
7. **图片输入是另一条链路**：保留原图、列出识别到的点/约束与不确定项、可编辑草稿、显式确认；只宣称已验证的题型，不默认打开无人监督自动绘图。

## 6. 约束和非目标

- 保持 React 19、TypeScript、Zustand、Three.js 0.186 和现有 npm workspaces；首期不增大型几何/AI 依赖。
- 保持旧 `.mgeo` 文件可读、点/棱/面依赖 ID 稳定、一次构造一步撤销；几何判定留在 `geometry-kernel`/`scene-graph`，UI 不重复求解。
- 保持现有 Alt 子图元选择、Shift 多选、旋转手柄、宿主点、剖切和自动取景可用；创建时不得触发视角抢夺。
- 不在 P0/P1 做完整 CAD、DWG/B-rep、真实 3D 视频动画生成、自动猜题意、无人确认的 Agent 写入、所有曲面之间的解析相交。
- 遇到退化、不可判定或缺能力，明示“不支持/需要补充条件”，不伪造结果。

## 7. 风险、测试口径与范围确认

- **风险**：拾取优先级和相机手势冲突；自动产生的点与拓扑点 ID 冲突；模板属性变更重建后手工编辑丢失；大型曲面性能；“教学虚线”与遮挡线语义混杂；截图模型虚构点/关系。
- **验证**：新增内核/场景单测、3D 交互组件与 Playwright 端到端测试；旧文档往返、撤销、相机、截面/交线回归；选 6 类高中样题做逐题验收。静态类型检查、lint、单测、构建和相关 e2e 当次执行，不沿用历史绿灯。
- **建议验收阈值（产品指标，需实测基线）**：从空白画布到三点一面，目标 ≤8 次主操作、无 Shift 多选；3D 创建模式全程可取消且无残留；上述 6 类样题均可完成、可保存恢复并一步撤销一次完整构造。效率/成功率需由教师实际任务测试验证，不能从源码推断。
- **范围已确认（2026-09-29）**：按本说明推荐方案推进——先立体，再评估平面/函数题型；球体与球截面列 P2 独立评审；“截图一键绘图”单列质量门禁与人工确认探索，不混入手工绘图首期。六类样题和真实教师/学生使用验收**尚未完成**。
