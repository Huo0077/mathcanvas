# 球体与球截面：解析图元设计

> 日期：2026-10-01。用户已决定启动球体与球截面；本文件是新范围的设计，不把既有外接球/内切球**读数**冒充可编辑球图元。执行进度只以 `docs/current-status.md` 为准，设计完成本身不是功能交付。

## 1. 用户工作与验收

教师在立体几何工作区输入球心 C=(1,2,3)、半径 5，确认后画布出现一只可选择、可改中心/半径、可一步撤销和保存重开的球。过 z=6 的平面切它，应得到球面交圆：圆心 (1,2,6)、半径 4，截圆方程及半径是解析值，不依赖显示细分数。平面 z=8 与球相切只给一点 (1,2,8)；z=9 与球无交；非单位法向与等价单位法向得到同一结论。主/俯/左/轴测工程投影视图都能读到球的圆轮廓，输出 SVG/DXF/PDF 与视图一致。球体表面积 `4πr²`、体积 `4πr³/3` 是带来源的精确读数。

## 2. 边界与方案选择

- **采用独立解析图元** `SpherePrimitive { id, type:"sphere", center:Vector3, radius:number, ...presentation }`。文档只存中心与正半径，不把 `SphereGeometry` 顶点或近似 `polyhedron3` 写进 `.mgeo`。UI 的球网格可以按屏幕质量改变段数而不改变几何、截面或持久数据；旧文档无迁移/语义变化。
- 创建首期明确提供**中心 + 正半径数值构造**，支持工具入口、未保存预览、确认、属性编辑与一步撤销。四点外接球、点驱动半径、球面绑定动点需要独立的约束/退化状态机，现有 S5 与总清单未要求这些构造，不伪装为本切片交付；保留按后续样题评审扩展的入口。
- **支持的截交**是球 ∩ 平面，写入现有 `SectionPrimitive`：圆 / 单点切触 / 空集。球 ∩ 球、球 ∩ 多面体的布尔整体和球 ∩ 圆柱/圆锥**不在本次实现范围**；对新建这些动作返回明确 `unsupported` 且事务 `changed=false`；旧文档若已含不支持的交集缓存，重算只给 `insufficient-data` 与诊断，不伪造多面体，也不把球强塞给仅接受凸多面体的布尔算法。
- 对比“球当作一个高面数 polyhedron3 模板”的方案：那会把 `segments` 与 `section.points` 误当解析真源，切面半径随细分变化、切点丢失，且把大量不可编辑顶点存进文档。本方案让球心/半径唯一地决定数学结果；代价是 3D 拾取、截面和投影要显式认识新图元，按各层的契约测试覆盖。

## 3. 文档、几何与退化语义

1. `packages/dsl/src/types.ts` 的 `PrimitiveSpec` 增加 `SpherePrimitive`；`schema.ts` 只接受三个有限坐标与有限严格正半径，非有限/零/负半径在提交和 `.mgeo` 导入边界都拒绝，错误定位到球的几何字段。`codec` 编解码保留 id、呈现属性及中心/半径，已有 schemaVersion 0.1 的旧类型逐字段不变。
2. 纯内核 `spherePlaneSection3(sphere, plane)`：设 `n̂=n/|n|`，有符号距离 `d=(n·center+constant)/|n|`，交圆心 `center−d·n̂`、半径 `sqrt(r²−d²)`。判别容差与模型尺度同源，非单位法向的常数也按同一比例处理；`|d|>r` 是空集、`|d|≈r` 是单点、`|d|<r` 是圆。零/非有限法向直接拒绝，不给虚假截圆。
3. 圆使用现有 `Conic3` / `CurvePiece3` 解析记录（完整参数域 `[0,2π]`），`section.exact.kind="circle"` 与 `status="exact"`；`section.points/loops` 仅是填充与旧消费者的可再生显示缓存。切点 `classification="point"` / `status="exact"`，画布要有可见点标记；不相交 `classification="none"` / `visible=false`，不能保留上一次的圆。禁止用固定 48 边形的面积或弦长冒充精确圆。
4. `sectionQuadric3` 目前把“无圆柱/圆锥轴向 bounds”解释为不可截；为球增加解析闭合圆分支，不改变圆柱/圆锥端面裁剪。多面体 `sectionPolyhedron3` 路径仍保持原样。球体派生面积/体积从 `radius` 计算，单位与精确度口径沿用测量组件。
5. 更新球心/半径、隐藏/锁定、拖动、删除、截面引用都走 `scene-graph` 事务与依赖图；移动球后截圆自动重算、一次移动一步撤销。删除球的截面按既有依赖保护/级联规则处理，不悬挂 `sourceId`。

## 4. 展示、投影与工具入口

- 3D 画布用 `THREE.SphereGeometry` 作为**显示网格**、`userData.primitiveId/type` 保持拾取身份；不把经纬细线变成用户可选棱。用现有 `solidMaterial`、选中/透明度和显示 tokens，不引入另一套硬编码颜色。经纬细分是渲染选择，文档无 `segments` 真源。
- “常用立体”新增球体 preset，字段为球心 X/Y/Z 与半径；编辑参数时仅替换预览、对象数不变，确认后一次提交。属性面板沿用可编辑坐标/半径控件；未提供不能工作但看似可点的“以四点定球”按钮。
- CAD 主/俯/左/轴测的正交投影中，球轮廓是以投影球心为圆心、投影尺度对应半径的闭合圆；`projectionVisuals.ts` 产生已存在的 `ProjectedPrimitive.polyline`，导出器不额外猜几何。透视 3D 画布使用光滑球网格，不把透视截图当工程正投影。
- Agent 的 `solid.create_sphere` 只有在 action registry、输入校验、编译器及文档验证贯通且脚本化验收通过后才进入模型可见工具集合；若阶段未完成，不登记“可用”动作。中文题干需要真实数值的中心/半径，缺参数走 `ask_user` 而非默选一个球。

## 5. 可交付边界与证据

| 范围 | 必须看到的证据 |
| --- | --- |
| 文档契约与保存 | 有效球 `.mgeo` 往返中心/半径/id/样式逐值相同；零半径、NaN、缺字段被拒；旧 fixture 继续加载。 |
| 解析截面 | 上述 z=6/8/9 三例，非单位法向等价，切点可见；改半径/球心后 `section.exact` 更新，无旧环残留。 |
| UI/撤销/场景 | 未确认预览不落盘；确认一次提交、属性栏可改、球可拾取、撤销恢复、保存重开后球/截圆可见且数值不变。 |
| 工程图/导出与测量 | 四视图球轮廓同半径；SVG/DXF/PDF 均输出它；表面积/体积精确值及来源在属性/画布可读。 |
| 不支持项 | 球-球/球-实体布尔计算明确拒绝、留下诊断、不改文档；外接球读数仍不是球图元。 |
| 门禁与上传 | 每个可独立验收的切片先红后绿；目标测试、typecheck/lint/build 和相关 e2e 实跑，更新 `current-status.md` 与过程记录，提交推送并 `git ls-remote` / CI 核对才勾选。 |

## 6. 发布边界

本方案只交付当前 `main` 的源码能力。GitHub 最新公开 Release 在本方案立档时为 v3.0；v3.0.1 只有 tag，旧 MSI/NSIS 不对应本方案。等后续计划范围冻结后再决定新发行版本、打包、安装实测和上传；设计或 CI 通过本身不等于“已发布桌面安装包”。
