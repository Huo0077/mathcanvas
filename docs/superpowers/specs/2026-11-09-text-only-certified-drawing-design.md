## 2. 要交付的合同与流程

```
原文文字题 → 单一题意 IR（原文 span、给定/目标/状态/来源、未知条件）
           → 明确路由：只读答题 / 必须作图 / 作图并答题
           → 语义构图计划（形状族、命名点、拓扑、构造关系、自由参数）
           → 独立构造与校验（实体存在、几何合法、每条题设条件、目标状态）
           → 候选图与题面/场景哈希绑定的核验记录
           → 用户预览 → 提交前 CAS 与重验 → 原子写入 / 拒绝并给原因
```

- **默认开启**：只有文字题适用的答案语义、目标追踪、数学核验和作图核验默认开启；保留显式回滚能力，但回滚时不得把“无核验图”作为已核验交付。已移除的 `imageRereadV1` 和图像依赖的三视图入口不因“全开”重新启用。现行 `rolloutPreferences.ts` 默认 0% 属于**待实施现状**，本方案不宣称已切换。第二模型调用仍需单独授权及预算，不因默认全开自动收费。
- **强制判别路由**：单选/纯答案不给绘图动作（此前 0% 文字题 9/20 未交付，多数误入画图）；只有原题明确要求“画/作/构造”才进入图形流程。只读答案允许“未独立核验”但不可伪装为已证明；作图草稿/提交严格按下一条执行。
- **作图完整性证书**：对每个作图目标产生含 `problemRevision`、`sourceRevision`、候选图哈希、场景版本、判据版本及义务总数的宿主记录。要求已识别的题设条件、必需图元/点名、拓扑、尺寸/关系全部有独立 `passed`；任何 `unknown`、`not_supported`、未消费条件、矛盾或空报告都不提供“正确图”确认入口。证书来自内核，不允许模型自报。验证通过也只证明在**支持的具体语义与实例**内正确，不冒充全称证明。
- **图元语义优先**：棱柱/棱锥/梯形/菱形/折片/棱上分点用已实现的构造器扩展；模型提交类型化实体别名和关系，不直接给未经约束求解的全套浮点顶点。需要直接坐标时由独立拓扑与残差判据兜底。非法面环/别名只允许有界、带精确错误路径的恢复，不可通过静默换题设或“按选项凑尺寸”修复。
- **阶段性错误**：`missing_given` 请求用户用文字补条件；`ambiguous_state` 只问折前/后、折角/对应点等关键问题；`unsupported_check` 明确说明当前不画；`refuted_relation` 给最小反例或残差；`stale_certificate` 拒绝提交并提示重新验证。任何缺口不得由空数组“全通过”或场景 revision 增长代替。

## 3. 先修的真实门禁漏洞

- `apps/web/src/agent/acceptance.ts` 的 `deriveAcceptance` 对多数文字作图题返回空；`agentRunner.ts` 在空时不传 `acceptance`；`coordinator.ts` 当前只在“有 acceptance 或已有 stagedVerification”时询问 `verificationGate`。改造目标：**对有作图动作的计划无条件要求完整证书**，而不是按模型答复中是否出现“画”或是否刚好生成核验报告决定是否拦截。纯文字只读回答不被图形证书误拦截。
- `ConfirmationPanel.tsx` 目前在 `diagramVerification === undefined` 时仍能显示“确认并提交”。UI 改为没有有效证书时只显示未核验原因和补条件/弃草稿；真正的权限检查同时存在于 `HostBridge.commit`/协调器，不能只靠隐藏按钮。 浏览器现构建复测还发现：四类立体题的真实文档提交和一步撤销均成功，但**含解答正文的消息在提交后仍显示“等待你确认”且继续保留确认按钮**；`RunStatus.progressOf` 把 `draft` 放在 `commit` 之前。这是独立的状态呈现/重复提交风险，必须在发证书或扩大默认比例前修复，并用“真实提交、状态已提交、按钮消失、再次确认拒绝且不重复实体”四项同时验收。
- 多题“图能编译/截图像”与“全部题设成立”不等价：完整性统计必须来自原题义务表，而不是只统计内核能识别的几条；做不到的题以覆盖率损失如实报告。

## 4. 度量、发布闸与非目标

指标分母固定：①尝试作图题数；②真正提交图数；③这些提交图中人工独立判定的题设错误数；④因歧义/不支持而未提交数；⑤已核验义务/全部必需义务（不能以可识别义务为分母冒充）。上线闸：冻结旧联考 30 题、四题和新文字留出题，不改原题；至少每题单次真实生产 UI 全流程及复测稳定性分轨报告；**提交图已知错误为 0**，任何未核验图有可点击提交即发布阻断。样本零错不证明无限题目“100%”；公开支持域边界与失败覆盖率。

本期不重启图片上传/识图，不打开无授权的第二模型，不自动把数值采样标为形式证明，不把推导正确率、选项正确率混成作图正确率。不在本方案编造“旧题现已全部通过”的新数据。
