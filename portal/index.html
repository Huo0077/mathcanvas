01 · ARCHITECTURE & CAPABILITIES

不止能画出来，
更是一个遵守数学法则的动态系统

v5.3.0 将大语言模型的题干理解、确定性解析几何内核与跨端原生外壳全面整合：模型只负责规划语义，所有坐标、切点、交面、二面角、线面角与空间直线夹角均由求解器算出并经独立证书检验，Windows 与 Android 共享同一套几何引擎。

02 · INTERACTIVE GALLERY

切换四大场景，细看每个工作区细节

点击任意截图可全屏放大检视标注、对象树与属性检查器中的真实数值读数。

边看图边对话：思考轨迹、数学证书、一键确认写入

  • 左侧对象栏将构造面归入独立「面（构造 / 辅助）」分组，避免被淹没在基础拓扑下。
  • 右侧 AI 抽屉先逐条核验 PA⊥平面 ABCD、E 是 PC 中点 等题设再允许写入，提交后支持 Ctrl+Z 一步还原。
  • 点击属性栏「在此面添加动点」，即可在刚生成的空间面上直接继续探究。

立体几何探究：多选联动、二面角与三维视图同步

  • 左栏「多选」与属性栏「三维视图联动」实时同步：透明面、隐藏边、法向量、展开图、旋转环一键切换。
  • 勾选任意两个面或按 Alt 拾取实体表面，即可测量二面角并复制精确数值与 sin / cos 表达式。
  • 拖动绑定动点时，所有关联线段与构造面仅按局部拓扑重算，保持高帧率流畅。

圆锥曲线与函数分析：精确求解交点、切线与渐近线

  • 识别高考题中的双曲线渐近线与圆相切条件（如 y² - x²/m² = 1），自动求出精确参数并绘制两条渐近线。
  • 支持 2D 动点沿曲线/圆滑轨拖动，过点切线与弦长实时联动。
  • 函数模块支持一次求导曲线与间断点分支隔离（如 1/x、tan(x) 不跨渐近线误连）。

工程制图（CAD）：立体几何直出 A4 标准四视图

  • 点击「改为投影立体几何的模型」，即时将 3D 场景转换为标准主视图、俯视图、左视图与轴测图。
  • 支持模型树、图层树与图纸树切换，切换至「2D 绘图」模式即可在图纸上补画几何尺寸标注。
  • 支持导出 SVG、DXF、PDF 及自包含 HTML 交互快照。

设置精简重构：一键获取模型，偏好设置一目了然

  • 内置 13 种国内外主流服务预设，填好地址和 Key 点「自动获取」，立即拉取模型下拉清单。
  • 桌面端采用 Windows 系统凭据管理器加密保存 API 密钥，配置文件不落明文。
  • 「偏好设置」集中管理字号密度、选中自动展开属性、3D 自动取景、新题自动清空旧图元及实验性开关。

04 · USER MANUAL

三步上手使用说明

无需复杂配置，下载安装包即可使用本地手工全功能工作台；接入任意大模型 Key 即可开启 AI 共创。

01

连接模型或直接打开画布

进入左侧 设置 → 模型服务，选择预设（如 DeepSeek / 通义 / Ollama），填入 API Key 后点击「自动获取」拉取模型名并保存验证；如仅作手工探究，无需密钥可直接使用全部几何工具。

02

用正常题干驱动 AI 构图

打开右下角或顶部 ✨ AI 助手，直接粘贴数学题干文本。Agent 会按需补全辅助线与构造面（如 面 AEC），先在隔离草稿确认核验结果，再点击「确认并提交」落盘。

03

拖拽探究、测量与多格式导出

点击棱或面上的「添加动点」即可绑定拖拽；勾选两面点「测量二面角」可查看精确 sin / cos；顶部「文件」支持导出 .mgeo、SVG、DXF、PDF 与自包含 HTML 交互快照。
