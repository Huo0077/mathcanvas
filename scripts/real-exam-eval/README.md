# 真题评测工具（2026-11-05）

> **历史档案（2026-11-09 起停用）**：产品已移除题图识别入口，仅支持文字输入。`live.eval.mjs` 现在会在发出任何 provider 请求前拒绝运行；下文旧图题采集、评分及结果仅供审计历史，不再作为可运行的图片实测步骤。文字题仍可使用已有评分器与开发集，但不能将旧 50 题图文混合成绩报告成当前功能成功率。

这是已经停用的图文混合评测档案，不修改产品 Agent，也不再提供付费识图入口。

## 已完成的样本

50 道公开高考客观题（2010–2022），30 道配图、20 道文字。来源固定版本、原始图像和参考答案保存在 `test-fixtures/real-exams-20261105`。不包含尚未核实来源的联考/模拟题，也不使用项目中自行编写的“真题风格”夹具。

## 历史资料的离线检查（不调用模型）

- 保留原始 50 题题集与图像文件供审计，当前产品只从其中 20 道**文字题**建立开发回归。执行：`node node_modules/vitest/vitest.mjs run scripts/real-exam-eval/production-entry-regression.test.ts`。
- 已保存的旧评分与报告可离线查看：`node --test scripts/real-exam-eval/score.test.cjs`。旧图题原始记录不删除，不继续调用视觉模型。
- `live.eval.mjs` 为**主动拒绝**的停用闸；任何人运行旧配置都会在发送模型请求前失败。新的文字题真实评测需另行冻结版本与文字题集、设置单次费用预算，不复用旧 50 题图文混合评测脚本。

## 历史输出与统计

旧批次每题保存完整事件、识图结构、最终输出、失败原因、草稿以及模型请求/响应。图片不在请求日志重复保存 base64，可从题库恢复。日志不包含凭据，但可能包含公开题目全文，不应未经检查公开。

- `summary.json`：交付、严格选项匹配、识图解析等原始统计。
- `progress.json`：中间进度。
- `{id}.json` / `{id}-requests.json`：逐题证据。
- 正式基线118次调用；材料修正中间轮8次、最终轮12次；另有预检8次及能力探测4次，共150次原生模型调用。价格未核实，不估算金额。

原始首轮3道材料有错标；其图片保存在首轮目录的 `input-sheets` 下。只修正材料并单独复测这3题：中间轮中文图注编码错误为??（0/3正确），修正编码后最终轮3/3正确，两个材料版本及结果均保留，不选择更优结果；正式首轮不可覆盖。分析报告同时列出首轮、排除错标材料的47题、材料修正后的合并观察结果。

统计脚本：`python scripts/real-exam-eval/summarize.py`，只读取已完成结果、不再请求模型。实际报告见仓库 `docs/audit/2026-11-05-real-exam-agent-evaluation-report.md`。

## 范围限制

真实使用产品的图像读取器、ModelPlanner 和 AgentRuntime，经桌面原生 provider 调用当前模型。不是模拟服务，也不是直接让独立聊天模型答题。但不覆盖 AgentRunner 特殊前置路由、UI点击、画布渲染和拖动交互；答案选项匹配不等价于证明或图形正确。
